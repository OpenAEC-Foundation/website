OpenAEC Foundation

Aan de slag

In 5 stappen begin je met het OpenAEC ecosysteem. Geen registratie, geen creditcard, geen vendor lock-in — gewoon downloaden en aan de slag.

1

Kies een tool die past bij jouw werk

Bekijk het complete ecosysteem en kies de tool voor jouw taak. Voor PDF-annotatie en CAD-tekeningen markeren: Open PDF Studio. Voor 2D CAD-tekenen: Open 2D Studio. Voor warmteverliesberekening volgens NEN 12831 en ISSO 51:2023: Open Heatloss Studio. Voor IFC-modelvalidatie: BIM Validator. Voor BCF issue-management: BCF Manager Studio. Voor kostenraming: Open Calc Studio.

Bekijk alle 18+ tools →
2

Download de installer of probeer de live demo

Op elke productpagina staan downloads voor Windows (.exe of MSI), macOS (.dmg), Linux (.deb, .AppImage, .snap, .rpm) en Android (.apk). Of klik op "Live demo" om direct in je browser te starten — geen installatie nodig.

Voorbeeld: Open PDF Studio downloads →
3

Installeer en start de tool

OpenAEC-tools zijn lichtgewicht (8-20 MB) dankzij Tauri 2 + Rust — veel kleiner dan Electron-apps. Op Windows kun je kiezen tussen System install (voor alle gebruikers, vereist admin) of User install (zonder admin-rechten). Op macOS sleep je de app naar Applications. Op Linux dubbelklik je de .deb of .AppImage. Geen account nodig om te starten.

Lees meer over de technische architectuur →
4

Werk met IFC of importeer bestaande data

Alle OpenAEC-tools communiceren via IFCX, een open uitbreiding van IFC die ook namespaces voor calculaties, rapporten en metadata ondersteunt. Importeer IFC 2x3, IFC 4 en IFC 4.3 modellen — inclusief civil schemas zoals IfcRoad, IfcRail, IfcBridge, IfcTunnel en IfcMarineFacility. Data stroomt naadloos tussen alle tools.

Meer over IFCX en civil schemas →
5

Geef feedback of draag bij

Stuur bugs en feature requests via GitHub (github.com/OpenAEC-Foundation). Doe mee in de WhatsApp-community of stuur een email naar info@open-aec.com. Voor bedrijven: vraag een offerte aan voor consultancy, managed hosting of custom extensions. Alle tools zijn LGPL-3.0 — fork, modificeer, draag bij.
