What is Open Pile Plan Studio?

An open-source engineering tool for reviewing pile options and assembling practical pile-plan variants. Structural loads, CPTs and available configurations come together in the browser and in the desktop apps for Windows, macOS and Linux, with the same Rust calculation core.

  • 1. Combine sources

    Import load points, CPTs and foundation advice and check their role.

  • 2. Assess options

    Inspect the plan view, the CPT selection, bearing capacity, utilization and cost.

  • 3. Record choices

    Assign configurations, review the whole plan and save everything as an IFCPP project.

Features

Start with the highlights or pick a topic.

01 Assess

See which piles work at every load point

Select one or more locations and review every pile option with size, tip level, status, utilization, cost and the governing load point. Compression and optional tension are checked separately. Assign a configuration to one location or to a whole selection at once.

Try it in the browser

02 Input

Three sources, one project

Import load points, CPTs and foundation advice from CSV or Excel and give each file its role before import. A preview shows how the columns are read. CPTs are selected per quadrant or within a maximum angle, and you can adjust that choice by hand for each location.

03 Optimize

The cheapest variant within your limits

The HiGHS optimization looks for the lowest cost within the limits you set for tip levels, sizes and the number of configurations. It can then reduce differences between neighbours within an extra cost budget. The result reports whether the optimum was proven.

Read more

04 Project

Variants side by side, everything in one file

Work with several pile-plan variants in one project, share configurations within groups and lock choices. Explore a different number of piles per pile cap with proposals from 1 to 20 piles. Save everything as an IFCPP file, with undo and redo.

  • Foundation advice in any shape

    One table row per value or an Excel matrix with one column per pile size, with a preview that shows how the file is read.

  • Refresh sources

    Read in new loads, CPTs or advice values and keep existing assignments and CPT selections where they still fit.

  • Import an existing pile plan

    Update a project from an Excel or CSV table, with checks on IDs and coordinates and a preview before import.

  • Select CPTs

    Automatically per quadrant or within a maximum angle, and overridable by hand for individual locations.

  • Compare pile options

    Valid, insufficient and missing options per location, with size, tip level and governing CPT.

  • Compression and tension

    Design loads in compression and, optionally, in tension are checked separately and both count when assigning and optimizing.

  • Utilization and cost

    Compare utilization, governing CPT and estimated cost before you record a configuration.

  • Assign one or many

    A configuration for one location or for a whole selection with common options.

  • Interactive selection

    Select by click, multi-selection or lasso and filter by pile size and tip level in the legend.

  • Minimize cost

    HiGHS finds the lowest cost within limits for tip levels, sizes and the number of configurations.

  • Fewer differences between neighbours

    Reduce differences in tip level and size between neighbouring locations within an extra cost budget, 5% by default.

  • Quick improve

    A fast local improvement method as an alternative to the full optimization.

  • Pile cap proposals

    Explore a different number of piles per pile cap, from 1 to 20, with indicative options and costs. The proposals are kept in the project.

  • Groups and locks

    Let locations in a group share the same configuration and lock assignments per plan.

  • Pile-plan variants

    Several named variants in one project, to compare plans side by side.

  • IFCPP project file

    Imported data, settings, pile choices and manual CPT selections together in one file, with undo, redo and recovery in the browser.

  • Export to Excel and CSV

    Pile assignments, proposed pile positions and CPTs to Excel or CSV, for reporting and coordination.

  • Browser and desktop

    The same Rust calculation core runs through WebAssembly in the browser and natively in the desktop apps for Windows, macOS and Linux.

  • MCP access for AI assistants

    The Windows app gives a local AI assistant access to the open project. Reading and editing are switched on separately.

  • Explore right away

    The browser demo opens with a complete sample project, so you can look at the workflow without any preparation.

Frequently asked questions

What does it cost?

Nothing. Open Pile Plan Studio is open source under the LGPL-3.0: no licence fees, no subscription and no account.

Can I use the results directly?

No. The app is a public alpha and supports engineering decisions, but it does not take over responsibility for the foundation design. The CPT selection is a practical approximation. Always have input, assumptions and results checked by a qualified professional.

What data do I need?

Three tables in CSV or XLSX: load points (ID, X, Y and the design load), CPTs (ID, X and Y) and foundation advice (CPT, pile tip level, pile size and bearing capacity). Levels in metres, sizes in millimetres and forces in kN. The browser demo includes a sample project to get started.

What is the difference between the browser and the desktop app?

Both calculate with the same Rust core. The desktop apps are linked to IFCPP files and reopen recent projects; the Windows app also has the connection with an AI assistant. In the browser you save projects as a download and the app keeps up to ten local copies.

Which systems does it run on?

Windows x64, macOS 15 or later on Apple silicon and Intel, Linux x64 as .deb or AppImage (tested on Ubuntu 22.04 and 24.04), and any modern browser.

How does the optimization work?

First the HiGHS solver looks for the lowest cost within your limits for tip levels, sizes and the number of configurations. It can then reduce the differences between neighbouring locations within an extra cost budget, 5% by default. The result states whether the optimum was proven. Quick improve is a faster, local method.

What can an AI assistant do with it?

The Windows app has MCP access. Switch the connection on in the settings, and a local assistant can read the open project, compare plans and start the optimization. Changes are only possible once you separately allow editing; every change goes through the same checks as in the app.

Are the downloads signed?

Yes. The Windows installer is digitally signed, the Mac version is signed and notarized by Apple, and the Linux packages have a detached OpenPGP signature. With the SHA256SUMS file you can verify all four installers.

Why Open Pile Plan Studio?

A pile plan is often manual work, spread across spreadsheets, foundation advice reports and drawings. Open Pile Plan Studio brings that information together in one workspace, so you see right away which configurations work and record your choices traceably. Free and open source, for structural engineers, geotechnical consultants and foundation specialists.
