In development

OpenAEC SuperCloud

SuperCloud brings Frappe, a CDE, document management and IFCX together in one environment for the entire construction project. The product is in development: currently with 6 major customers, opening worldwide on 1 January.

This week: 47 improvements to infrastructure and deployment.

  • The application layer runs on AWS Fargate in the test environment, with multiple backend instances
  • Test and production use the same deployment scripts, with a runbook for production deployment
  • A status dashboard with measurements every 5 minutes and backups for each customer environment
  • The BIM platform shows previews on project and model cards and is more stable
  • The forum runs as a separate app, with sign-in through your OpenAEC account

What is new in each tool

Open BIM Suite

311 improvements · 9 accounts · +93,584 lines · 3 issues resolved · 5 releases

  • First drawing delivered with our own BIM modeller (not yet production-ready)
  • Docs now works as a file explorer and document manager
  • IFCX has its own tab and also displays regular IFC files
  • Modeller: alignment, elevation dimensions and copying grids
  • Structural drawings with beam labels and a pile layout with schedule

  • New formats: OpenDRIVE, URDF, VTK, MagicaVoxel, Gaussian splats, COPC and 3MF
  • Open analysis models from SAF and FEM text files
  • View a clash in section, with an image attached to the issue
  • Save a session as a project file

Open Geotechniek Studio

6 improvements · 1 account · +4,330 lines · 2 releases

  • 3D ground model as a full workspace, with tabs and a section box with handles
  • Aquifers, GeoTOP voxels and monitoring wells load automatically
  • Assess pile-driving records using six driving formulas
  • Compare blows from the driving record with the prediction from the cone penetration test
  • Tension pile calculations and an improved cone penetration test overview
  • Sheet pile library for the calculation modules
