Pioneers — People

The people who had the courage to think differently. Who gave their work away so the world would be better for it.

Linus Torvalds 🇫🇮

Creator Linux kernel & Git
"Talk is cheap. Show me the code."

The man who built the world's operating system as a hobby project, and later created Git to enable the collaboration of thousands of developers.

Guido van Rossum 🇳🇱

Creator Python
"Beautiful is better than ugly. Simple is better than complex."

The Dutchman who created the most popular programming language in the world. Python is the language of AI, science and the web.

LinkedIn

Ton Roosendaal 🇳🇱

Creator Blender, Blender Foundation

In 2002, crowdfunded €100,000 in 7 weeks to buy Blender free from the bankrupt NaN Technologies. Today Blender is the industry standard for 3D creation.

LinkedIn

Thomas Krijnen 🇳🇱

Creator IfcOpenShell, AECgeeks

The man behind the open BIM revolution. IfcOpenShell is the backbone of open source BIM tools and makes it possible to read, write and manipulate IFC files.

LinkedIn

Dion Moult 🇦🇺

Lead developer Bonsai (BlenderBIM), IfcOpenShell contributor

Pioneer in open source BIM tools. Bonsai makes it possible to create full-fledged BIM models in Blender, entirely open source.

LinkedIn

Mark Shuttleworth 🇿🇦

Founder Ubuntu/Canonical
"Computer is not a device anymore. It is an extension of your mind."

First African in space. Founded Canonical and made Linux accessible to everyone with Ubuntu.

LinkedIn

Rushabh Mehta 🇮🇳

Founder ERPNext/Frappe

Open source ERP that challenges SAP. Frappe Framework and ERPNext prove that enterprise software doesn't have to be expensive and closed.

LinkedIn

Antonio González Viegas 🇪🇸

Founder That Open Company (IFC.js)

"An architect who started coding" — brought open BIM to the web. That Open Company makes it possible to view and edit IFC models directly in the browser.

LinkedIn

Richard Stallman 🇺🇸

Founder GNU Project & Free Software Foundation (1983)
"Free software is a matter of liberty, not price."

The godfather of free software. Without GNU and the GPL there would be no open source movement as we know it.

Dennis Ritchie 🇺🇸 †2011

Creator C & co-creator UNIX

Without C and UNIX there would be no Linux, no Python, no internet as we know it. The quiet hero whose work made literally everything possible.

Graydon Hoare 🇨🇦

Creator Rust programming language (at Mozilla)

Rust: the language OpenAEC is built on. Safety, speed and reliability without compromises.

Solomon Hykes 🇫🇷

Creator Docker

Revolutionized software deployment with containers. Docker made it possible to run software identically anywhere.

Frank Karlitschek 🇩🇪

Founder Nextcloud

Open source alternative to cloud storage. Nextcloud gives users back control over their own data.

Open Source Projects

The tools and frameworks on which OpenAEC is built. Each project represents years of unpaid work by passionate developers.

Linux

The operating system that runs the world. From servers to smartphones.

Python

The language anyone can learn. From scripting to machine learning.

Blender

3D creation for everyone. Modeling, animation, rendering and more.

IfcOpenShell

The backbone of open BIM. Reading, writing and manipulating IFC files.

Bonsai (BlenderBIM)

BIM modeling in Blender. Full-fledged BIM authoring, entirely open source.

That Open Company

Open BIM on the web. Viewing and editing IFC models in the browser.

ERPNext / Frappe

Open source ERP. Accounting, project management, CRM and more.

Nextcloud

File management and collaboration. Your data, your server, your rules.

Docker

Containers for deployment. Running software identically everywhere.

Rust

Safe systems programming language. Speed without compromising safety.

LibreOffice

Free office applications. Documents, spreadsheets and presentations for everyone.

Ubuntu

Linux for everyone. The operating system that brought Linux to the desktop.

Git

Version control for the world. Collaborating on code at a global scale.

Three.js

3D graphics on the web. The foundation for interactive 3D experiences in the browser.

PDF.js

PDF rendering in the browser. Open source alternative to proprietary PDF viewers.

Tauri

Lightweight desktop apps. Web tech with native performance and small bundles.
