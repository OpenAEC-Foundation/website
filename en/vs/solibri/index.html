OpenAEC vs Solibri

Open source BIM validation with BIM Validator, BCF Manager Studio and Monty IFC Viewer — built on open standards like IDS, NL-BIM Basis ILS and the RVB BIM Norm.

Solibri Office has been one of the established names in BIM model validation and model checking since 2000. It offers an extensive rule library for clash detection, code compliance and QA/QC, with workflows refined over decades. Solibri Office typically costs €2,000-5,000 per user per year (subscription or perpetual + maintenance), depending on edition and country.

OpenAEC offers an open source stack for BIM validation: BIM Validator for IFC and IDS validation, BCF Manager Studio for issue management and Monty IFC Viewer for model inspection. The tools are browser-based or native, free, and built on open standards such as IDS (buildingSMART), NL-BIM Basis ILS and the RVB BIM Norm.

BIM Validator

Validate IFC models against IDS specifications, NL-BIM Basis ILS and RVB BIM Norm. Browser-based, no installation.

BCF Manager Studio

Issue management with BCF 2.1 and BCF API 3.0. Self-hosted or local, seamless integration with BIM Validator.

Monty IFC Viewer

Lightweight IFC viewer for inspecting geometry, properties and relationships. Open source and cross-platform.

When do you choose which?

Choose OpenAEC when...

  • You work in the Dutch market and want direct support for NL-BIM Basis ILS or RVB BIM Norm.
  • You want to use IDS (the open buildingSMART standard) as your primary validation mechanism.
  • You want browser-based validation — no installation, easy to share with clients and partners.
  • You don't want to pay a €2,000-5,000 annual subscription.
  • You want to work self-hosted without vendor lock-in.
  • You want to use BCF API 3.0 natively for issue exchange.
  • You're a smaller organization or freelancer that needs professional BIM validation.

Choose Solibri when...

  • You need a very extensive, proven rule library with decades of refinement.
  • You run advanced clash detection and code compliance workflows.
  • Your organization has worked in Solibri workflows for years with existing rule sets.
  • You need commercial support with an SLA, including consultancy.
  • You use specific Solibri plug-ins deeply embedded in your pipeline.
  • License cost isn't an issue and you prefer maximum coverage and stability.
