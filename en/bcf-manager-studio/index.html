BCF Manager Studio

Open-source BCF 2.1 issue management platform for BIM projects. Manage issues, communicate with teams and link to IFC models.

In development
26 commits · Rust + TypeScript · By 3BM Bouwkunde

What is BCF?

BIM Collaboration Format (BCF) is an open standard (buildingSMART) for exchanging issues and comments between BIM software. It enables reporting, discussing and resolving problems in a building model — regardless of which software the parties involved are using.

  • Open standard: BCF 2.1 (XML) and BCF API 3.0 (REST)
  • Software-independent: works with any BIM package that supports BCF
  • Viewpoints: visual snapshots of the 3D model for each issue
  • Metadata: priority, status, assignment, deadlines, labels

Why BCF Manager Studio?

Existing BCF tools are often part of expensive, proprietary BIM platforms. BCF Manager Studio offers a standalone, open-source alternative that anyone can use — free, without license fees, without vendor lock-in.

The platform runs locally or on your own server. Your data stays yours. Connect it to your own IFC viewer, share issues with your team, and export to any BCF-compatible package.

Features

BCF 2.1 issue management

Create, edit and manage issues conforming to the BCF 2.1 standard. Full support for topics, comments, viewpoints and snapshots.

Viewpoints with 3D snapshots

Link visual viewpoints to issues with camera position, selection and visibility. Directly visible in your IFC viewer.

Team collaboration

Assign issues to team members, set deadlines, add comments and track status. Real-time synchronization between all participants.

BCF XML import/export

Import and export BCF files (XML format) for exchange with Solibri, Navisworks, BIMcollab and other BCF-compatible software.

REST API (BCF API 3.0)

Full BCF API 3.0 implementation for integration with external tools, dashboards and automation.

Project management

Organize issues per project with labels, priorities, milestones and filters. Clear dashboard with statistics.

IFC integration

Link issues directly to IFC elements via GlobalId. Navigate from an issue directly to the relevant element in your model.

Self-hosted

Run the platform on your own server or locally. Full control over your data, no cloud dependency.

Notifications

Receive notifications for new issues, status changes and replies. Configurable per project and per user.

Technology

Rust TypeScript Tauri 2 BCF 2.1 XML BCF API 3.0 REST API Docker

Built with the same technology stack as the entire OpenAEC ecosystem: a Rust backend for performance and security, a TypeScript frontend for usability, and Tauri 2 for cross-platform distribution.
