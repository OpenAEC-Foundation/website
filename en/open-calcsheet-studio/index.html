Open CalcSheet Studio

Calculations you can read back, in one report

Write your calculation line by line as text, and the app works it out with units and readable formulas. Next to calculation sheets, a project can hold spreadsheets, formula canvases, node graphs, drawings and notebooks. Together they become one report.

Hugely inspired by Calcpad

Calcpad by Ned Ganchovski is really what led to this app. You write a calculation as plain text and read back every step worked out: that idea comes from there, and we are grateful to him for it. Open CalcSheet Studio has its own calculation kernel, but it also opens your .cpd files. The open-source line of Calcpad continues in the community edition CalcpadCE.

Frequently asked questions

Which files can I open?

IFCX projects (.ifccalculation, .ifcx), calculation text (.cpd), workbooks (.xlsx), Markdown, notebooks (.ipynb, .py) and PDF as a sheet. DXF is converted to a drawing in a sheet, and a graph reads .dyn files. IFC4x3 can be exported but not opened.

Do I have to install anything?

No, the app also runs in the browser, although file dialogs, saved settings and the Jupyter sheet do not work there. For full use there is a desktop app. It has no built-in updater: install a new version over the old one; your projects stay ordinary files.

What does it cost?

Nothing. Open CalcSheet Studio is open source under the LGPL-3.0: no licence fees and no account.

In which file format is my work saved?

In IFCX, an open format. Every sheet is in it with its text, input and results. You can also export to IFC4x3, .xlsx, Markdown and PDF.

Which systems does it run on?

Windows (x64), macOS (universal, Apple silicon and Intel), Linux (.deb and AppImage) and the browser. Jupyter and Marimo are only tested on Windows, and the report straight to PDF is Windows only; other systems use the print dialog.

Does it fit construction practice?

The modules calculate to EN 1995-1-1, EN 1993-1-1 and EN 1992-1-1 with the Dutch national annex. Every module has a status: the beam and the two-pile cap are "to be checked". The app does not replace the judgment of a structural engineer, so check the results yourself.

What can an AI assistant do with it?

The desktop app has a built-in MCP server and REST API with the same 43 tools: open and save projects, add sheets, set input, calculate, export and print. It only listens on your own computer, behind a token, and you can switch it off or make it read-only.

How reliable are the results?

With every change, 56 check scripts run on Linux and Windows, including 121 results compared against hand calculations. Every result shows its formula and filled-in numbers, so you can follow it yourself.
