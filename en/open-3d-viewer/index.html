Open 3D Viewer Studio

Free viewer to open, measure and section building models

Open models from SketchUp, Tekla, Revit and IFC without the program they were made in. Orbit around them, measure, cut the model open and save it as IFC. As a desktop app for Windows, macOS and Linux, or right in the browser.

01 Open

Opens what you are sent

SketchUp, Tekla, Revit, IFC, glTF, OBJ, STL, PLY, CityJSON, LandXML and DWG or DXF, without the program the model was made in. The File page keeps your recent files at hand, so you can pick up right where you left off.

02 Revit and IFC

Revit models with their schedules

The desktop app opens .rvt and .rfa with levels, grids, rooms and saved views, and IFC models with their spaces in a layer of their own. A schedule, such as a door schedule, opens as a table below the model; click a row and its elements are selected.

See the model the way you want

Switch between solid, wireframe and edges, and between perspective and orthographic. Turn to a side with the view cube or look straight down, and switch layers on or off in the explorer.

See how it fits together

Pull the model apart per storey or per element, with a slider per axis. Cut it open with a section box or a section plane with filled cuts, and measure distances, angles, areas and polygons.

A workspace you already know

The window follows the OpenAEC Blueprint, like the other OpenAEC apps: a ribbon with Home, View and Measure, an explorer, properties and a status bar. Choose from five themes, work in English or Dutch and give every command your own shortcut.

Frequently asked questions

Which files can I open?

On the desktop and in the browser: SketchUp (.skp, version 3 and later), Tekla Structures (.db1, beta), glTF and GLB, Wavefront OBJ, STL, PLY, CityJSON and CityJSONSeq, terrain as a TIN from LandXML, and DWG and DXF (only the faces from model space, not a full CAD drawing). Only in the desktop app: IFC (.ifc) and Revit (.rvt, .rfa), with levels, grids, rooms, saved views and schedules.

Do I need to install anything?

No. Open 3D Viewer Studio also runs in the browser, on WebGPU, and your file is not uploaded. For IFC and Revit you need the desktop app, for Windows, macOS or Linux. The OpenAEC Installer installs and updates all your OpenAEC apps in one go.

What does Open 3D Viewer Studio cost?

Nothing. The app is free and open source under the LGPL-3.0-or-later. No subscription, no account and no per-user license fees.

In which file format is my work saved?

Save as creates an IFC 4 file, on the desktop and in the browser. The geometry is saved as triangles (IfcTriangulatedFaceSet), with the storeys, classes, properties and materials of the model. That way you can turn a SketchUp or Tekla model into IFC, for example. The original file stays as it was.

Which systems does it run on?

Windows 10 and 11 (x64), macOS 11 or later (universal: Apple silicon and Intel) and Linux (x86-64, as .deb, .rpm, AppImage or .tar.gz). And in any browser with WebGPU. The window is in English and Dutch.

Does it fit the way construction works?

Yes. It opens the models that architects, engineers and builders exchange, from SketchUp and Tekla to Revit and IFC, as well as city models in CityJSON and terrain from LandXML. Whatever you open, you can save as IFC 4, the open standard for BIM.

What can an AI assistant do with it?

With the MCP server open-3d-viewer-mcp (Model Context Protocol, an open standard), an AI assistant such as Claude Code, Claude Desktop or another MCP client operates the desktop viewer the way you do: opening files, looking around, selecting, reading properties, cutting sections and measuring. You see it happen in your own window. Everything stays on your computer: the viewer only listens on 127.0.0.1, with a token.

Can I view several models at once?

Yes. Open replaces the model you are viewing; Add puts another file next to it, for example the structure next to the architecture. Every model has its own toggle to show or hide it. IFC spaces sit in a layer of their own and start hidden.

What can it not do yet?

IFC and Revit open only in the desktop app. Textures become an average colour. Tekla profiles are approximated; that reader is still in beta. From DWG and DXF only the faces come along, without ACIS solids, text, dimensions and curves. And the browser version does not respond while a large model is loading.

How do I know the download is genuine?

The installers are signed: Windows with Authenticode, macOS with a Developer ID and notarized by Apple, Linux with the OpenAEC OpenPGP key (fingerprint 13F6 D414 ADEE 4ED4 CD09 AC60 601D 86C9 3C50 4D29). Every release includes SHA256SUMS and its signature SHA256SUMS.asc, and every file has a GitHub build attestation.

Technology

For those who want to know how it is built.

Rust

One Rust code base for the desktop app and the browser version.

iced

The interface is built with iced, a GUI library in Rust, without a web view or JavaScript framework.

Own renderer on wgpu

An own 3D pipeline on wgpu with 4x anti-aliasing: native on the desktop, on WebGPU in the browser.

WebAssembly

In the browser the same code runs as WebAssembly. Models are read locally; nothing goes to a server.

OpenAEC Blueprint

Window, design tokens, fonts and icons come from the OpenAEC Blueprint, the standard for all OpenAEC apps.

MCP server

open-3d-viewer-mcp connects an MCP client to the window, only through 127.0.0.1 and with a token.
