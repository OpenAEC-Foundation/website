Open CAD Studio

Open source CAD that reads and writes DWG and DXF itself

Draft in 2D, model in 3D and lay out on paper, on the desktop and in the browser. Open CAD Studio is built in Rust, renders on the GPU and opens your drawings without a conversion service. An open source project by Hakan Seven and a growing group of contributors, supported and promoted by the OpenAEC Foundation.

Community project

Made by Hakan Seven and contributors

Open CAD Studio was not developed by the OpenAEC Foundation. Hakan Seven started the project in March 2026; by now about eighty people have contributed, the foundation among them. It fits our mission: open software for the whole construction chain, without depending on a single vendor.

Features

From the first line to a plotted layout

Start with the highlights or pick a topic.

01 Files

DWG and DXF without a detour

Open, edit and save DWG and DXF directly, and choose a version from R14 up to 2018 when you save. External references, blocks with attributes and a backup or autosave file open as well.

Read more

02 Drafting

Draft the way you are used to

The command line, object snaps and tracking, layers with filters, hatches, tables and dynamic blocks. If you have worked with DWG for years, you will find the commands under their familiar names, also in a classic workspace.

Read more

03 3D

Solids on a real geometry kernel

Extrude, revolve, sweep, loft and Boolean operations, with ACIS solids from existing drawings. The GPU draws large models smoothly, orthographic or in perspective.

Read more

04 Automation

Plug-ins, scripts and an AI assistant

Extend the app with plug-ins, run command scripts or convert drawings without a window. Through the built-in MCP server an AI assistant can read drawings, draw and take screenshots; the node graph builds geometry without code.

  • DWG and DXF

    Read and write, with save as R14 up to 2018.

  • External references

    Attach, reload and bind xrefs, and write blocks out with WBLOCK.

  • Import

    PDF, DGN V8, SVG, OBJ meshes, raster images and survey points from LandXML.

  • Export

    STL and STEP AP203 for 3D, CSV with object data and IFCCAD as an open drawing format (experimental).

  • 2D drafting

    Lines, polylines, arcs, ellipses, splines and revision clouds, with object snaps and tracking.

  • Modify

    Offset, trim, extend, fillet, array, mirror and more, also with grips and properties.

  • Layers and filters

    A layer manager with filters, groups and layer states, and quick select by property.

  • Hatches

    Patterns and gradients, with islands, boundaries and annotation scale.

  • Dimensions and text

    Dimensions, leaders, tolerance frames, tables and fields, with your own styles.

  • Blocks with attributes

    Dynamic blocks with parameters, actions and visibility states, and attributes edited in one form.

  • Layouts and viewports

    Model space and paper space with scaled viewports, page setups and plot styles (CTB/STB).

  • Plot and publish

    Layouts to PDF or the printer, several sheets in one PDF, and comparing two drawings.

  • Solids

    Box, sphere, cylinder, extrude, revolve, sweep, loft and Boolean operations.

  • ACIS from drawings

    3DSOLID, REGION and BODY objects from DWG and DXF are shown correctly.

  • Fast on the GPU

    2D and 3D display through wgpu, also for large drawings with many objects.

  • Works with an AI assistant

    An MCP server lets an assistant read, edit and capture the drawing.

  • Node graph

    Build drawings with nodes for every object the drawing commands make.

  • Plug-ins and scripts

    Native plug-ins from a registry, command scripts and conversion without a window.

  • Your own workspace

    Your own ribbon panels, shortcuts and toolbars, or the classic workspace.

Frequently asked questions

What does it cost?

Nothing. Open CAD Studio is open source under the GPL-3.0: no licence fees, no subscription and no account.

Who makes Open CAD Studio?

Hakan Seven is the creator and maintainer. Dozens of developers contribute as well, also from the OpenAEC Foundation. The foundation does not own the project, but supports it and builds Open Infra Studio on it.

Can I use my existing DWG drawings?

Yes. DWG and DXF are read and written directly, without a conversion service, and you choose a version from R14 up to 2018 when you save. The app is still in active development: keep a copy of important drawings and report problems on GitHub.

What is the difference between the web version and the desktop app?

Both use the same core. In the browser you open drawings through the browser and save them as a download. The desktop app associates itself with DWG and DXF files, prints, creates PDFs and runs plug-ins, scripts and the MCP server.

Which systems does it run on?

Windows and Linux on x64 and ARM64, macOS on Apple silicon and Intel, and any modern browser. On Windows you can also install it through winget.

How often is there a new version?

Every week, usually on Sunday. The version number is the year plus the week number, such as 2026.45. The download buttons on this page always point to the newest version.

What can an AI assistant do with it?

The desktop app has an MCP server. With it an assistant can open drawings, query and create objects, run commands, check and save, and take screenshots of the drawing window. You see everything happen in the app.

Which languages is the app available in?

In 23 languages, including Dutch, English, French, Turkish and Spanish.
