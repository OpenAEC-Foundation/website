OpenAEC Foundation

Get started

Start with the OpenAEC ecosystem in 5 steps. No registration, no credit card, no vendor lock-in — just download and get going.

1

Pick the tool that fits your work

Explore the complete ecosystem and pick the tool for your task. For PDF annotation and CAD markup: Open PDF Studio. For 2D CAD drawing: Open 2D Studio. For heat-loss calculations per NEN 12831 and ISSO 51:2023: Open Heatloss Studio. For IFC model validation: BIM Validator. For BCF issue management: BCF Manager Studio. For cost estimation: Open Calc Studio.

View all 18+ tools →
2

Download the installer or try the live demo

Every product page offers downloads for Windows (.exe or MSI), macOS (.dmg), Linux (.deb, .AppImage, .snap, .rpm) and Android (.apk). Or click "Live demo" to start straight in your browser — no installation needed.

Example: Open PDF Studio downloads →
3

Install and launch the tool

OpenAEC tools are lightweight (8–20 MB) thanks to Tauri 2 + Rust — much smaller than Electron apps. On Windows you can choose between System install (all users, admin required) or User install (no admin needed). On macOS, drag the app into Applications. On Linux, double-click the .deb or .AppImage. No account required to start.

Read more about the technical architecture →
4

Work with IFC or import existing data

All OpenAEC tools communicate via IFCX, an open extension of IFC that also supports namespaces for calculations, reports and metadata. Import IFC 2x3, IFC 4 and IFC 4.3 models — including civil schemas like IfcRoad, IfcRail, IfcBridge, IfcTunnel and IfcMarineFacility. Data flows seamlessly between all tools.

More on IFCX and civil schemas →
5

Send feedback or contribute

File bugs and feature requests via GitHub (github.com/OpenAEC-Foundation). Join the WhatsApp community or email info@open-aec.com. For companies: request a quote for consultancy, managed hosting or custom extensions. All tools are LGPL-3.0 — fork, modify, contribute.
