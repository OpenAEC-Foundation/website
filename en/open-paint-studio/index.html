Open source image editor

Open Paint Studio

Sketch, mark up and touch up, without a heavy photo editor

A simple image editor in the spirit of MS Paint, in the OpenAEC house style. Draw, mark up and edit images, keep shapes and text editable as vector objects, and let an AI assistant join in through the API and MCP server.

Features

Light, fast and editable

Start with the highlights or pick a topic.

01 Drawing

Mark up in a few clicks

Brush, eraser, fill, eyedropper, lines, rectangles and ellipses, with adjustable size, opacity and a colour palette. Ideal for marking up a screenshot, sketching a floor plan or annotating a photo.

02 Text

Text straight on the canvas

Type text into the image and pick font and size. Click the text later to change it. The fonts are bundled, so it works without an internet connection too.

03 Vector objects

What you draw stays editable

With Keep vector objects you select, move, resize and restyle shapes and text afterwards; Ctrl+A grabs everything at once. Cropping, rotating and flipping leave the objects intact, and you export them as editable SVG.

04 Formats

Opens almost any image, on your own computer

The editor reads common images itself; for TIFF, PSD, HEIC, JPEG XL, camera RAW and more, ImageMagick is built in as WebAssembly. Nothing goes to the cloud. Export to PNG, JPEG, WebP or SVG, or keep the image in IFCX.

    Undo or redo the last 40 steps, and a draft that is kept when you close the window.

  • Image editing

    Crop, resize, rotate and flip. Vector objects are kept along the way.

  • Colour corrections

    Brightness, contrast, saturation, greyscale, invert and sepia.

  • Open

    PNG, JPEG, WebP, GIF, BMP, TIFF, HEIC/HEIF, AVIF, PSD, SVG, ICO, TGA, JPEG 2000, JPEG XL, camera RAW and IFCX/IFCXB.

  • Export and save

    Export to PNG, JPEG, WebP or SVG, or keep the image in IFCX or IFCXB.

  • All local

    No upload to the cloud. Your draft is saved on your own device as you work.

  • Zoom and focus mode

    Ctrl+scroll zooms from 10% to 400%, dragging with the middle mouse button pans the canvas, and focus mode (F11) gives the drawing area the whole window.

  • Five themes, two languages

    Light, Forge, OpenAEC, Blueprint and high contrast, in Dutch and English.

  • Local API

    An API on 127.0.0.1 with a token of its own. Send the current image to the API or load a document from it; a revision check stops two programs from overwriting each other's work.

  • API and MCP

    A local API with its own token and an MCP server, so an AI assistant such as Claude can open and edit images.

  • File associations

    Open an image or an IFCX/IFCXB document with a double-click in your file manager.

Frequently asked questions

What does it cost?

Nothing. Open Paint Studio is open source under the MIT licence; the OpenAEC house style and the logo are licensed under CC BY-SA 4.0. No licence fees, no subscription and no account.

Which systems does it run on?

Windows (64-bit), macOS on Apple and Intel processors, and Linux on x86-64 as an AppImage, .deb or Snap. The editor also runs as a browser app, but there is no public version of it yet; you start it yourself from the source code.

Which files can I open and save?

Open: PNG, JPEG, WebP, GIF, BMP, TIFF, HEIC/HEIF, AVIF, PSD, SVG, ICO, TGA, JPEG 2000, JPEG XL, supported camera RAW variants and IFCX/IFCXB. Export: PNG, JPEG, WebP and SVG; saving (Ctrl+S) keeps the image in IFCX. A multipage or animated file opens as a single image, and SVG and PSD become a raster image when opened.

Do my shapes and text stay editable?

Yes, as long as Keep vector objects is on (it is by default). Shapes, brush strokes and text stay separate objects, also after rotating, flipping or resizing. Colour corrections flatten the image; undo brings the objects back. For editable vectors outside the app, export SVG.

Does it work with an AI assistant?

Yes. The MCP server gives an assistant tools to create an image, draw on it, undo a step and get the result back as a PNG. The server uses the same local API as the editor. Both are separate Node processes that you start from the source code; the installers do not start them.

Do my images go to the cloud?

No. The extra image formats are read locally too, by a built-in ImageMagick in WebAssembly. Your draft is saved on your own device as you work, and the API listens on your own computer only.

How large can an image be?

A file of up to 64 MB and 64 megapixels. The working canvas is scaled down proportionally to at most 4096 pixels per side and 8 megapixels. The editor works with 8 bits per channel; HDR and layers are not kept.

Which languages does the interface come in?

Dutch and English, with five themes: light, Forge (dark), OpenAEC, Blueprint and high contrast.

Technology and licence

For those who want to know how it is built.

Tauri 2 and Rust

A small desktop app that uses the system web view; the same editor also runs in the browser.

TypeScript and Vite

The editor itself, with the ribbon components and themes of the OpenAEC style book.

ImageMagick in WebAssembly

Reads the less common image formats locally, in a separate worker.

API and MCP

Separate Node processes; the API listens on 127.0.0.1 only and asks for a token, the MCP server talks over stdio.

IFCX

The image can be kept in an IFCX or IFCXB document, so it fits alongside building information.

Licences

The editor and the services are licensed under MIT; the OpenAEC house style, the logo and the components from the style book under CC BY-SA 4.0.
