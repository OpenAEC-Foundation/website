The Journey

  1. January 2026

    OpenAEC Foundation starts

    • First repositories created
    • Open PDF Studio and Open 2D Studio started
    • Frappe Claude Skill Package published (55 stars)
  2. February 2026

    The ecosystem grows

    • Open Pointcloud Studio, Open Energy Studio, Open Heatloss Studio started
    • Dynlex (196 commits), OpenAEC Reports (255 commits)
    • IFC Factory for IFCX development
  3. March 2026

    Validation & documentation

    • OpenAEC BIM Validator (207 commits)
    • Open Field Studio launched (v0.1.3)
    • Open Speech Studio (v0.5.0)
    • 19 Claude Skill Packages published
    • BCF Platform and OpenAEC Docs started
    • Website live at open-aec.com
  4. April 2026

    Foundation being established

    • Stichting OpenAEC Foundation i.o.: incorporation in preparation
    • 50 repositories, 2,428+ commits
    • 10+ live demos available
    • Quote system and supporters programme launched
  5. May 2026

    Costing & release notes

    • Open Calc Studio started: open source cost estimating for the construction sector
    • Live release notes on every product page
    • Civil engineering and infrastructure added to the scope
  6. June 2026

    Website in four languages

    • Site in Dutch, English, French and Turkish
    • Automatic language selection on the first visit
    • Open PDF Studio v3 started
    • Extension catalogue for Open Planner Studio
  7. July 2026

    Biggest month of growth

    • 11 new repositories
    • OpenAEC Installer: install and update every tool in one place
    • Open 3D Studio started: 3D modelling with IFC as its native format
    • Pile Plan Studio and the SuperCloud desktop client started
    • News in four languages
  8. August 2026

    Building knowledge & discoverability

    • IFCCAD: open CAD drawing models in Rust
    • Master Builder library with building knowledge, standards and drawings
    • Site made discoverable for search engines and AI assistants
    • Open CAD Studio featured on the homepage
  9. September 2026

    Five languages

    • Website in Spanish as well
    • Open PDF Studio: complete feature overview
    • Over 3,400 stars across all repositories
  10. October 2026

    One-click downloads

    • Download buttons start the download right away
    • Open Pointcloud Studio 0.8.0, now native
    • Socials page with QR code
    • 62 repositories, 18,000+ commits, 4,200+ stars and 130,000+ downloads
  11. December 2026planned

    Ecosystem complete

    • All tools in production
    • IFCX namespaces completed
    • End-to-end open source AEC chain

      Largest repos

        AI discoverability

        Our strategy for getting AI assistants such as Claude, ChatGPT, Grok, Perplexity and Gemini to recommend the OpenAEC tools to their users. This is called Generative Engine Optimization (GEO).

        Implemented

        • /llms.txt: LLM-friendly site summary (emerging standard)
        • /robots.txt: explicitly allows 24 crawlers, including ClaudeBot, GPTBot and PerplexityBot
        • /sitemap.xml: full URL index for crawlers, in five languages
        • /api/tools.json: machine-readable tool catalogue (19 tools)
        • Schema.org JSON-LD on the homepage (Organization + 13 SoftwareApplication)
        • FAQPage JSON-LD: directly usable by Google AI Overviews
        • HowTo JSON-LD: getting-started steps for AI Overviews
        • Open Graph cards: rich previews when shared on LinkedIn, Slack and WhatsApp
        • Comparison pages: versus AutoCAD, BIMcollab, Bluebeam, Bouwprijs, Dragon and Solibri
        • Markdown mirrors: Claude, Cursor and Continue read .md more cleanly than HTML

        Next steps

        • Submit the sitemap to Google Search Console and Bing Webmaster Tools
        • Links from authoritative sources (buildingSMART, OSArch, awesome-bim, awesome-rust)
        • Dedicated Markdown documentation per tool (more extensive SDK and examples)
        • MCP servers for more tools: direct integration with AI assistants
        • Blog and case studies, in English too: international visibility
        • Presence on Stack Overflow, Reddit and Hacker News
