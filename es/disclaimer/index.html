Fundación

La OpenAEC Foundation (Stichting OpenAEC Foundation) está establecida en los Países Bajos y se rige por el Derecho neerlandés. La fundación es una organización sin ánimo de lucro.

Licencias open source

Todo el software de la OpenAEC Foundation se publica bajo licencias open source reconocidas (MIT, LGPL, CC BY-SA). Consulta los repositorios individuales en GitHub para conocer la licencia concreta de cada proyecto.

Declaración de sala limpia (clean room)

En la medida en que la OpenAEC Foundation desarrolla software que interopera con formatos de archivo cerrados (propietarios), esto se hace exclusivamente sobre la base de ingeniería inversa en sala limpia, de conformidad con la Directiva europea de Software (Directiva 2009/24/CE).

Er wordt geen gebruik gemaakt van beschermde broncode, vertrouwelijke documentatie of gelekte informatie van derden. Alle implementaties zijn gebaseerd op publiek beschikbare specificaties, eigen analyse en onafhankelijk onderzoek.

Privacidad

La OpenAEC Foundation no recopila datos personales a través de sus herramientas. Las herramientas que se ejecutan en local procesan todos los datos en tu propio dispositivo. Para los servicios alojados se aplica nuestra política de privacidad.

Responsabilidad

El software se proporciona "tal cual", sin ninguna garantía. La OpenAEC Foundation no es responsable de los daños derivados del uso del software. Consulta la licencia open source específica de cada proyecto para ver las cláusulas completas de exención de responsabilidad.
