BIM Validator

Comprueba modelos IFC frente a requisitos IDS

Carga un modelo IFC, elige NL BIM Basis ILS, la RVB BIM Norm o tu propio archivo IDS y ve, elemento a elemento, qué falta. Revisa los errores en 3D y pásalos a tu equipo como incidencias BCF. Como aplicación de Windows, como paquete de Python o en tu propio servidor.

Del modelo IFC a los hallazgos

Empieza por lo más destacado o elige un tema.

01 IDS

Comprueba tu modelo frente a los requisitos

Elige NL BIM Basis ILS (12 especificaciones), la RVB BIM Norm (26 especificaciones) o tu propio archivo IDS. Para cada especificación ves cuántos elementos la cumplen y cuáles no, con el GlobalId, la clase IFC y el motivo.

02 3D

Ve en 3D dónde está el problema

El modelo aparece junto a los resultados. Haz clic en un hallazgo y el visor se acerca al elemento, con sus propiedades al lado. Con los planos de sección miras dentro del edificio, y puedes cargar varios modelos a la vez.

03 BCF

Los hallazgos como incidencias BCF

Convierte una especificación no superada en una incidencia BCF con punto de vista y exporta la lista como archivo BCF 2.1. También puedes abrir un archivo BCF, ver los puntos de vista, cambiar el estado y volver a exportarlo. Los comentarios y los autores se conservan.

04 En tu ordenador

Una aplicación, un paquete o un servidor

La aplicación de Windows lleva el servidor de validación integrado, así que tu modelo se queda en tu ordenador. Guarda los proyectos en local o en un almacenamiento de proyectos conectado. Para comprobar modelos en un script o una canalización, usa el paquete de Python o la API HTTP.

  • Validación IDS

    Comprueba un modelo IFC frente a cualquier archivo IDS, con cumple o no cumple por elemento.

  • NL BIM Basis ILS v2

    12 especificaciones, entre otras sobre el nombre de las plantas, NL-SfB, los espacios, la estructura portante, la resistencia al fuego y los materiales.

  • RVB BIM Norm v1.1

    26 especificaciones de la Agencia Inmobiliaria del Estado neerlandés, como los datos del proyecto, la ubicación del terreno, las plantas, los espacios y NL-SfB por tipo de elemento.

  • Tu propio archivo IDS

    Carga los requisitos de tu propio proyecto u organización.

  • IFC2X3 e IFC4

    Ambos esquemas, desde cualquier programa BIM que exporte IFC.

  • Informes en JSON y HTML

    Guarda los resultados para compartirlos o procesarlos después.

  • Visor 3D

    Gira, desplaza y amplía el modelo, con un cubo para elegir la dirección de vista.

  • Árbol del modelo y propiedades

    Navega del proyecto al elemento y consulta la información, los conjuntos de propiedades, las cantidades y el tipo.

  • Planos de sección

    Planos de sección en X, Y y Z que seleccionas y arrastras en la vista 3D.

  • Cinco temas

    Claro, oscuro, Blueprint y dos temas de alto contraste.

  • Exportación BCF 2.1

    Los hallazgos con punto de vista y captura de pantalla en un solo archivo BCF.

  • Abrir archivos BCF

    Abre un archivo .bcf o .bcfzip, salta al punto de vista y cambia el estado.

  • No se pierde nada

    Al exportar se conservan los identificadores de las incidencias, los autores, los comentarios y las imágenes. Volver a importar no sobrescribe tus incidencias locales.

  • Línea de comandos

    ifc-validate model.ifc --ids nl-bim para lotes, scripts y canalizaciones de CI.

  • Biblioteca de Python

    Usa el núcleo de validación por separado en tu propio código, sin la aplicación.

  • API HTTP

    Sube un modelo, sigue la validación como una tarea y recoge el BCF cuando esté listo.

  • Servidor MCP

    Deja que un asistente de IA compruebe modelos, liste los estándares y cree informes en local.

  • En tu propio servidor

    Un contenedor con la interfaz web y la API, que se ejecuta como usuario normal.

Preguntas frecuentes

¿Ya puedo usar el BIM Validator?

Puedes probarlo: hay versiones preliminares para Windows y un paquete de Python. La herramienta sigue en desarrollo, así que no uses todavía sus resultados como única comprobación en proyectos reales.

¿Cuánto cuesta?

Nada. El código fuente se puede usar libremente con la licencia MIT. Los componentes de IfcOpenShell que realizan la validación tienen licencia LGPL-3.0 o posterior.

¿Qué es IDS?

La Information Delivery Specification es un estándar abierto de buildingSMART para recoger requisitos de información en un archivo XML que el software puede leer. Un archivo así indica, por ejemplo, que cada muro debe tener un código NL-SfB y una resistencia al fuego. El validador comprueba elemento a elemento si el modelo lo cumple.

¿Cumple mi modelo el estándar si todo se supera?

No necesariamente. Los archivos IDS incluidos para NL BIM Basis ILS y la RVB BIM Norm son una interpretación propia de esos estándares. Superarlos significa que el modelo cumple esa interpretación, no cada requisito de la fuente. Los requisitos que no se pueden expresar en IDS requieren una evaluación aparte.

¿Adónde va mi modelo?

El visor 3D muestra el modelo en tu propio ordenador. Para la validación, el modelo va al servidor de validación: en la aplicación de Windows es un servidor que se ejecuta en tu propio ordenador; en una instalación propia, tu propio servidor.

¿Funciona en macOS o Linux?

Todavía no hay instalador para macOS ni para Linux. El paquete de Python (Python 3.11 o 3.12) sí funciona, con la línea de comandos y la biblioteca, y puedes construir tú mismo el servidor como contenedor.

¿Qué tamaño puede tener un modelo?

Cuenta con unas diez veces el tamaño del archivo en memoria. Un modelo de 200 MB necesita, por tanto, unos 2 GB de RAM.

¿Cómo funciona junto con BCF Manager Studio?

Exporta los hallazgos como archivo BCF e impórtalo en BCF Manager Studio o en cualquier otro programa que lea BCF 2.1. Está prevista una conexión directa.

Tecnología

Un núcleo de validación independiente en Python, con un visor, un servidor y una aplicación de Windows a su alrededor.

IfcOpenShell e ifctester

Las bibliotecas de código abierto que leen el modelo IFC y lo comprueban frente a los requisitos IDS.

Python y FastAPI

El núcleo de validación, la línea de comandos y un servidor que ejecuta las validaciones en segundo plano.

React y That Open Engine

El visor 3D, basado en Three.js y web-ifc, con la interfaz de OpenAEC Blueprint.

Tauri

La aplicación de Windows, con el servidor de validación integrado y un instalador firmado.

IFC, IDS y BCF

Los estándares abiertos de buildingSMART para el modelo, los requisitos y los hallazgos.

Docker

Un contenedor con la interfaz web y la API, que se ejecuta como usuario normal y tiene una comprobación de estado.
