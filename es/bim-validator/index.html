BIM Validator

Herramienta open source de validación de IFC. Valida modelos contra especificaciones IDS, normas neerlandesas y requisitos de proyecto: en el navegador, por CLI o por API.

Funcionalidades

Validación

Validación IDS

Valida modelos IFC contra archivos Information Delivery Specification (IDS). Cada especificación se comprueba por elemento con resultado pass/fail y mensajes de error detallados.

NL BIM Basis ILS v2

Norma básica BIM neerlandesa integrada con 12 especificaciones: nomenclatura de plantas, clasificación NL/SfB, atributos de espacios, estructura portante, superficies exteriores, resistencia al fuego, valor U, materiales y estado de renovación.

RVB BIM Norm v1.1

Norma integrada del Rijksvastgoedbedrijf (la agencia inmobiliaria del Estado neerlandés) con 27 especificaciones para proyectos de construcción públicos: información de proyecto, coordenadas del emplazamiento, NL-SfB por tipo de elemento, propiedades estructurales & de seguridad contra incendios e información de zonas.

Subida de IDS personalizado

Sube tu propio archivo de especificación IDS (máx. 10MB) para validar contra requisitos específicos del proyecto o de la organización.

Multiesquema

Admite los esquemas IFC2X3 e IFC4: compatible con exportaciones de Revit, ArchiCAD, Tekla y otro software BIM.

Informes a nivel de elemento

Para cada elemento que falla se muestran el GlobalId, la clase IFC, el nombre del elemento y un mensaje de error detallado.

Visor 3D

Visor 3D WebGL

Vista 3D interactiva del modelo IFC en el navegador mediante That Open Engine (Three.js). Sin instalación ni plugins.

Selección de elementos

Haz clic en un elemento del visor 3D para ver sus propiedades, o haz clic en un error de la lista de resultados para resaltar el elemento en 3D.

Navegación de cámara

Orbita, desplaza y haz zoom por el modelo. Botón fit-all para encuadrar el modelo completo.

Paneles redimensionables

División triple arrastrable: panel de navegación (izquierda), visor 3D (centro) y panel de detalle (derecha). Todos los paneles son plegables.

Exportación BCF

Exportación BCF 2.1 ZIP

Exporta todos los errores de validación como archivo ZIP BCF 2.1. Cada elemento que falla se convierte en un topic BCF con viewpoint, importable directamente en Revit, Solibri, BIMcollab o Navisworks.

Integración con BCF Platform

Conéctate a la OpenAEC BCF Platform para enviar incidencias directamente a un panel de proyecto central. Incluye autenticación OIDC y selección de proyecto.

Cola de incidencias

Vista local de las incidencias BCF generadas, con miniaturas y detalle expandible, antes de exportar o enviar a la plataforma.

Interfaces

Aplicación web

Interfaz totalmente basada en el navegador con subida por arrastrar y soltar, selección de norma, barra de progreso, vista de resultados y visor 3D.

CLI

ifc-validate model.ifc --ids nl-bim — apta para procesamiento por lotes, pipelines de CI/CD y scripting. Salida por consola, JSON o HTML.

API REST

Backend FastAPI con endpoints de validación asíncronos. Integrable en tus propios flujos de trabajo, paneles o herramientas de terceros.

Informes & salida

Panel de resultados

Tarjeta resumen con el total de pass/fail, porcentaje, número de elementos validados y marca de tiempo.

Desglose por especificación

Lista expandible por especificación con estado pass/fail, porcentaje y una lista paginada de elementos que fallan.

Exportación JSON

Descarga los resultados completos de la validación como archivo JSON estructurado para análisis posterior o archivado.

Informe HTML

Genera un informe HTML autónomo para compartirlo con el equipo de proyecto o el cliente.

Procesamiento de archivos

Subida por arrastrar & soltar

Arrastra archivos IFC, IFCXML o IFCZIP al navegador. Máximo 500MB por archivo.

Gestión de memoria

Comprobación automática de si hay suficiente RAM disponible (los archivos IFC usan ~10 veces su tamaño en memoria). Los archivos temporales se limpian de inmediato.

Archivos grandes

Optimizado para modelos IFC de hasta 1GB o más. Indicador de progreso durante el procesamiento.

Despliegue & integración

Despliegue con Docker

Configuración completa de Docker Compose con backend, frontend, nginx, PostgreSQL y Redis. Un solo comando para arrancarlo todo.

On-premises

Ejecuta el validador en tu propio servidor para un control máximo sobre los datos y la privacidad. Sin dependencia de la nube.

Multi-tenant

Almacenamiento de proyectos con integración opcional de NextCloud para la gestión de archivos por organización.

Autenticación SSO

Single sign-on basado en OIDC para entornos empresariales.
