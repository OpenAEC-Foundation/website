Credits

Un homenaje a los pioneros del open source. Antes de que fuera cool. Antes de que existiera la IA. Cuando Microsoft aún llamaba a Linux un cáncer. Ellos construyeron los cimientos sobre los que seguimos construyendo.

El open source gana

Los números no mienten. El open source ya no es una alternativa: es el estándar.

Blender
300K+
Descargas por semana. De herramienta de nicho a estándar del sector. Usado por Netflix, NASA y Epic Games.
Linux
96%
De todos los servidores funcionan con Linux. El 85 % de todos los smartphones (Android), los 500 mayores superordenadores.
Python
#1
Lenguaje de programación del mundo (TIOBE 2026). Del scripting a la IA, de la web a la ciencia.
LibreOffice
200M+
Usuarios en todo el mundo. La alternativa gratuita para las aplicaciones ofimáticas.
ERPNext
170+
Países donde se usa ERPNext. ERP open source que desafía a SAP y Oracle.
Nextcloud
50M+
Usuarios. La alternativa open source a Dropbox, Google Drive y OneDrive.

Pioneros — Personas

Las personas que tuvieron el valor de pensar diferente. Que regalaron su trabajo para que el mundo fuera mejor.

Linus Torvalds 🇫🇮

Creador del kernel Linux & Git
"Talk is cheap. Show me the code."

El hombre que construyó el sistema operativo del mundo como proyecto de hobby, y que después creó Git para hacer posible la colaboración de miles de desarrolladores.

Guido van Rossum 🇳🇱

Creador de Python
"Beautiful is better than ugly. Simple is better than complex."

El neerlandés que creó el lenguaje de programación más popular del mundo. Python es el lenguaje de la IA, la ciencia y la web.

LinkedIn

Ton Roosendaal 🇳🇱

Creador de Blender, Blender Foundation

En 2002 recaudó por crowdfunding 100 000 € en 7 semanas para liberar Blender de la quebrada NaN Technologies. Hoy Blender es el estándar del sector para la creación 3D.

LinkedIn

Thomas Krijnen 🇳🇱

Creador de IfcOpenShell, AECgeeks

El hombre detrás de la revolución open BIM. IfcOpenShell es la columna vertebral de las herramientas BIM open source y hace posible leer, escribir y manipular archivos IFC.

LinkedIn

Dion Moult 🇦🇺

Desarrollador principal de Bonsai (BlenderBIM), colaborador de IfcOpenShell

Pionero de las herramientas BIM open source. Bonsai hace posible crear modelos BIM completos en Blender, totalmente open source.

LinkedIn

Mark Shuttleworth 🇿🇦

Fundador de Ubuntu/Canonical
"Computer is not a device anymore. It is an extension of your mind."

El primer africano en el espacio. Fundó Canonical y, con Ubuntu, hizo Linux accesible para todo el mundo.

LinkedIn

Rushabh Mehta 🇮🇳

Fundador de ERPNext/Frappe

ERP open source que desafía a SAP. Frappe Framework y ERPNext demuestran que el software empresarial no tiene por qué ser caro y cerrado.

LinkedIn

Antonio González Viegas 🇪🇸

Fundador de That Open Company (IFC.js)

"Un arquitecto que se puso a programar": llevó el open BIM a la web. That Open Company hace posible ver y editar modelos IFC directamente en el navegador.

LinkedIn

Richard Stallman 🇺🇸

Fundador del Proyecto GNU & la Free Software Foundation (1983)
"Free software is a matter of liberty, not price."

El padrino del software libre. Sin GNU y la GPL no existiría el movimiento open source tal como lo conocemos.

Dennis Ritchie 🇺🇸 †2011

Creador de C & cocreador de UNIX

Sin C y UNIX no habría Linux, ni Python, ni internet tal como lo conocemos. El héroe silencioso cuyo trabajo hizo posible literalmente todo.

Graydon Hoare 🇨🇦

Creador del lenguaje de programación Rust (en Mozilla)

Rust: el lenguaje sobre el que está construido OpenAEC. Seguridad, velocidad y fiabilidad sin compromisos.

Solomon Hykes 🇫🇷

Creador de Docker

Revolucionó el despliegue de software con los contenedores. Docker hizo posible ejecutar software de forma idéntica en cualquier lugar.

Frank Karlitschek 🇩🇪

Fundador de Nextcloud

Alternativa open source al almacenamiento en la nube. Nextcloud devuelve a los usuarios el control sobre sus propios datos.

Proyectos Open Source

Las herramientas y frameworks sobre los que está construido OpenAEC. Cada proyecto representa años de trabajo no remunerado de desarrolladores apasionados.

Linux

El sistema operativo que hace funcionar el mundo. De servidores a smartphones.

Python

El lenguaje que cualquiera puede aprender. Del scripting al machine learning.

Blender

Creación 3D para todos. Modelado, animación, renderizado y más.

IfcOpenShell

La columna vertebral del open BIM. Leer, escribir y manipular archivos IFC.

Bonsai (BlenderBIM)

Modelado BIM en Blender. Autoría BIM completa, totalmente open source.

That Open Company

Open BIM en la web. Ver y editar modelos IFC en el navegador.

ERPNext / Frappe

ERP open source. Contabilidad, gestión de proyectos, CRM y más.

Nextcloud

Gestión de archivos y colaboración. Tus datos, tu servidor, tus reglas.

Docker

Contenedores para el despliegue. Ejecutar software de forma idéntica en cualquier lugar.

Rust

Lenguaje de programación de sistemas seguro. Velocidad sin comprometer la seguridad.

LibreOffice

Aplicaciones ofimáticas gratuitas. Documentos, hojas de cálculo y presentaciones para todos.

Ubuntu

Linux para todos. El sistema operativo que llevó Linux al escritorio.

Git

Control de versiones para el mundo. Colaborar en código a escala global.

Three.js

Gráficos 3D en la web. La base de las experiencias 3D interactivas en el navegador.

PDF.js

Renderizado de PDF en el navegador. Alternativa open source a los visores de PDF propietarios.

Tauri

Apps de escritorio ligeras. Tecnología web con rendimiento nativo y paquetes pequeños.

Estamos sobre hombros de gigantes. Cada línea de código que escribimos fue posible gracias al valor de estos pioneros. El open source no es una tendencia: es el futuro.
