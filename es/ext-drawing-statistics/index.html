Extensión para Open 2D Studio

Drawing Statistics

Extensión que muestra recuentos de formas y estadísticas del dibujo. Añade una pestaña de cinta Complementos con un botón de recuento de formas y un comando de terminal.

Descargar v1.0.1 (1,4 KB) Ver código fuente

Funciones

Pestaña de cinta Complementos

Añade un botón de recuento de formas a la pestaña de cinta Complementos en Open 2D Studio.

Comando de terminal

Registra un comando de terminal stats show para mostrar estadísticas desde la línea de comandos.

Recuento de entidades

Cuenta todas las entidades por tipo en el dibujo actual.

Requiere Open 2D Studio v0.15.0 o posterior.
