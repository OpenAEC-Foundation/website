BCF Manager Studio

Plataforma open source de gestión de incidencias BCF 2.1 para proyectos BIM. Gestiona incidencias, comunícate con los equipos y vincúlalas a modelos IFC.

En desarrollo
26 commits · Rust + TypeScript · By 3BM Bouwkunde

¿Qué es BCF?

BIM Collaboration Format (BCF) es un estándar abierto (buildingSMART) para intercambiar incidencias y comentarios entre software BIM. Permite notificar, discutir y resolver problemas en un modelo de construcción, con independencia del software que utilicen las partes implicadas.

  • Estándar abierto: BCF 2.1 (XML) y BCF API 3.0 (REST)
  • Independiente del software: funciona con cualquier paquete BIM compatible con BCF
  • Viewpoints: instantáneas visuales del modelo 3D para cada incidencia
  • Metadatos: prioridad, estado, asignación, plazos, etiquetas

¿Por qué BCF Manager Studio?

Las herramientas BCF existentes suelen formar parte de plataformas BIM caras y propietarias. BCF Manager Studio ofrece una alternativa independiente y open source que cualquiera puede usar: gratis, sin costes de licencia, sin vendor lock-in.

La plataforma se ejecuta en local o en tu propio servidor. Tus datos siguen siendo tuyos. Conéctala a tu propio visor IFC, comparte incidencias con tu equipo y exporta a cualquier paquete compatible con BCF.

Funciones

Gestión de incidencias BCF 2.1

Crea, edita y gestiona incidencias conforme al estándar BCF 2.1. Soporte completo de topics, comentarios, viewpoints e instantáneas.

Viewpoints con instantáneas 3D

Vincula viewpoints visuales a las incidencias con posición de cámara, selección y visibilidad. Visibles directamente en tu visor IFC.

Colaboración en equipo

Asigna incidencias a miembros del equipo, fija plazos, añade comentarios y sigue el estado. Sincronización en tiempo real entre todos los participantes.

Importación/exportación BCF XML

Importa y exporta archivos BCF (formato XML) para el intercambio con Solibri, Navisworks, BIMcollab y otro software compatible con BCF.

API REST (BCF API 3.0)

Implementación completa de BCF API 3.0 para la integración con herramientas externas, paneles y automatización.

Gestión de proyectos

Organiza las incidencias por proyecto con etiquetas, prioridades, hitos y filtros. Panel claro con estadísticas.

Integración IFC

Vincula incidencias directamente a elementos IFC mediante el GlobalId. Navega desde una incidencia directamente al elemento correspondiente de tu modelo.

Self-hosted

Ejecuta la plataforma en tu propio servidor o en local. Control total sobre tus datos, sin dependencia de la nube.

Notificaciones

Recibe notificaciones de nuevas incidencias, cambios de estado y respuestas. Configurables por proyecto y por usuario.

Tecnología

Rust TypeScript Tauri 2 BCF 2.1 XML BCF API 3.0 REST API Docker

Construido con la misma pila tecnológica que todo el ecosistema OpenAEC: un backend en Rust para rendimiento y seguridad, un frontend en TypeScript para la usabilidad y Tauri 2 para la distribución multiplataforma.
