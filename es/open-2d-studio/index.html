Funciones

Herramientas de dibujo

Línea, rectángulo, círculo, arco, polilínea, elipse y texto. Entrada de comandos al estilo CAD para un control preciso.

Precisión y referencias

Ajuste a rejilla y referencias a objetos: punto final, punto medio, centro, intersección. Sistema de rejilla configurable.

Gestión de capas

Múltiples capas con controles de visibilidad, bloqueo y color. Organiza los dibujos en grupos lógicos.

Importación/exportación DXF

Lee y escribe archivos DXF mediante el backend Rust dxf-rs para la interoperabilidad con AutoCAD, BricsCAD y otro software CAD.

Propiedades y selección

Edita el color de trazo, el grosor y el estilo de línea. Haz clic, selecciona por recuadro o usa Mayús+clic para componer selecciones. Alineación y distribución de selecciones múltiples.

Extensiones

Arquitectura extensible para complementos. Consulta Drawing Statistics como ejemplo de extensión.

Stack tecnológico

Tauri 2.0

~10 MB de tamaño de aplicación, ~30 MB de uso de RAM, rendimiento nativo gracias al backend en Rust.

React 18 + TypeScript

Interfaz basada en componentes con tipado seguro y gestión de estado con Zustand.

Renderizado Canvas 2D

Renderizado rápido que maneja con fluidez más de 10 000 elementos.
