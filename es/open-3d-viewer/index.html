Elige el formato y la plataforma

La importación Revit e IFC funciona en la aplicación de escritorio. La versión web usa WebGPU y admite menos formatos. Los archivos pueden mostrarse de forma incompleta o distinta de su aplicación original.

FormatoEscritorioWebQué debes saber
Revit .rvt / .rfaSíNoCategorías, niveles, ejes, habitaciones y vistas guardadas, según los datos del archivo.
IFC .ifcSíNoGeometría, posiciones, unidades y huecos; elementos seleccionables con tipo IFC, GlobalId y propiedades disponibles.
SketchUp .skpParcialParcialLector parcial para archivos clásicos y 2021+. Algunos modelos fallan; las texturas se muestran como tonos de color.
Tekla .db1BetaBetaDepende de la versión y es incompleto. Los perfiles pueden ser cajas aproximadas; cortes, desfases, rotaciones y chaflanes no se aplican por completo.
glTF .gltf / .glbSíSíEn el navegador: GLB o glTF con búferes integrados. Las texturas aparecen como tonos de color medios.
Wavefront .objSíSíColores MTL en escritorio; sin representación completa de texturas.
STL .stlSíSíASCII y binario.
PLY .plySíSíASCII y binario, con caras. No se admiten nubes de puntos sin caras.

Todavía no se admiten STEP, DWG/DXF, FBX ni formatos de nubes de puntos como E57 y LAS. Tampoco hay modo de paseo, varios modelos simultáneos ni representación completa de texturas.

Escritorio y web

Desarrollado en Rust con iced y wgpu. La aplicación se orienta a Windows, Linux y macOS; la versión web requiere WebGPU. El código del visor usa LGPL-3.0-or-later. La versión de escritorio estándar también incluye un lector Revit propietario, por lo que el paquete completo no es totalmente de código abierto.
