Open Calculations Studio

App de escritorio de código abierto para cálculos estructurales — inspirada en CalcPAD, con exportación directa a IFC4x3 STEP e IFCX JSON-LD. Anteriormente Ifc-Calc, reconstruida bajo la OpenAEC Foundation.

¿Qué es Open Calculations Studio?

Open Calculations Studio es una herramienta moderna de código abierto para cálculos estructurales — inspirada en CalcPAD, la herramienta muy extendida entre los ingenieros estructurales neerlandeses y europeos. Reconstruimos todo el motor de cálculo en TypeScript con compatibilidad con la sintaxis CalcPAD, y añadimos exportación IFC e IFCX en vivo para que los cálculos se integren directamente con los modelos BIM.

  • Compatible con CalcPAD — los archivos .cpd existentes funcionan sin cambios
  • Consciente de unidades — mm, kN, N/mm², mm⁴ mediante mathjs
  • Exportación en vivo a IFCX + IFC4x3 STEP — un cálculo se convierte de inmediato en un elemento BIM
  • Renderizado KaTeX — fórmulas matemáticas con fracciones reales, subíndices y superíndices y letras griegas
  • Dibujos SVG — diagramas paramétricos directamente dentro del cálculo
  • Casos de carga — SLS / ULS / sísmico en pestañas separadas
  • Utilizable como biblioteca — intégrala en aplicaciones FEM o comprobaciones normativas

¿Por qué Open Calculations Studio?

CalcPAD lleva años siendo utilizado por ingenieros estructurales neerlandeses para cálculos manuales. Pero es de código cerrado, solo funciona en Windows y no tiene integración BIM incorporada. Open Calculations Studio lleva la funcionalidad de CalcPAD a la tecnología web moderna: multiplataforma, de código abierto y con exportación IFC directa.

El archivo de regresión 2259-Intertek-units.cpd, de 1094 líneas, se evalúa con 0 errores y renderiza 6 dibujos SVG. Suficiente para cálculos de proyectos reales.

Funciones

Fórmulas con unidades

Trabaja con mm, kN, N/mm², mm⁴ y todas las unidades del SI. Mathjs se encarga de la aritmética consciente de unidades y la simplificación automática (b*h → mm²).

Composición matemática

Renderizado KaTeX con fracciones reales, superíndices, subíndices y letras griegas (σ, ε, ρ, Φ, ψ). Las fórmulas muestran nombre = fórmula = valores sustituidos = resultado en una sola línea.

Vista previa en vivo

Editor de panel dividido (CodeMirror 6) con resaltado de sintaxis para .cpd. La vista previa con debounce se vuelve a renderizar mientras escribes.

Casos de carga

Pestañas para SLS / ULS / sismo, etc., cada una con sus propios valores de entrada para las variables. Un documento, múltiples escenarios.

Compatible con CalcPAD

Totalmente compatible con archivos .cpd existentes: #if/#else if/#end if, #repeat, #for, macros #def, #include, $Plot, matrices, búsquedas.

Exportación IFC4x3 STEP

Detecta elementos estructurales mediante nombres de variable convencionales (b_fdn, l_fdn, D_paal, M_Ed, R_c_d). Genera un esqueleto válido Project → Site → Building → Storey.

IFCX JSON-LD

Exportación IFCX (borrador) en vivo — la próxima generación de IFC con espacios de nombres para cálculos, normas y metadatos. Cálculo y modelo BIM en un solo formato.

Dibujos SVG

Macros SVG paramétricas con interpolación de valores. @img(file.svg) incrusta dibujos externos en línea. @svg ... @end para SVG escrito a mano.

Pestaña IFC

Visor STEP integrado y visor IFCX JSON con resaltado de sintaxis. Los tipos de entidad clicables enlazan directamente con la documentación de buildingSMART.

Carga de GEF

Carga con @gef nombre — usa los datos de sondeos directamente en los cálculos de cimentación. Se integra con Open Geotechniek Studio.

5 temas

Light, Forge, OpenAEC, Blueprint y Contrast — todos construidos sobre los design tokens de OpenAEC. Elige el que mejor funcione en tu entorno.

Exportación a PDF

Exportación a PDF lista para imprimir mediante el shell de Tauri con vista previa headless. Lista para el expediente del proyecto o la revisión de terceros.

Modo biblioteca

Usa @ifc-calc/core como biblioteca TypeScript: analiza, evalúa, renderiza y genera IFC/IFCX desde apps FEM o comprobaciones normativas.

Compatibilidad con CalcPAD

Totalmente compatible como subconjunto con archivos CalcPAD reales. Funciona de inmediato con tus documentos .cpd existentes:

  • "Title, 'prose, // comment
  • #if … #else if … #else … #end if, #hide / #show / #pre / #post
  • #repeat n … #end repeat en #for var = lo : hi … #loop (incl. nested)
  • #def name(p1; p2; …) … #end def macros, #def Name$ = literal constants
  • #include filename.cpd — externe macro-libraries en SVG drawings
  • $Plot{ … @ x = lo : hi } — inline parametrische plots
  • Subscript-comma's (V_b,0), $-getypeerde refs, matrix [a;b|c;d]
  • Format-specs (:F2), dotted/percent identifiers
  • mathjs Matrix-aware take, hlookup, hlookup_ge, vlookup, get

Perfiles de usuario

Ingenieros estructurales

Cálculos manuales de vigas, pilares y cimentaciones — directamente en un documento legible. Abre tus archivos CalcPAD existentes sin migración.

Modeladores BIM

Vincula los cálculos directamente a elementos IFC. Sin transferencia manual de valores — la comprobación vive en el modelo.

Educación & formación

Los estudiantes de ingeniería estructural aprenden a calcular con la sintaxis real que encontrarán en la práctica. Código abierto — sin costes de licencia.

Desarrolladores FEM

Integra @ifc-calc/core en tu propia aplicación FEM para preprocesado/posprocesado o comprobaciones normativas. Biblioteca TypeScript, instalable con npm.

Tecnología

TypeScript React 19 Rust Tauri 2 mathjs KaTeX CodeMirror 6 Vite npm workspaces

Monorepo con tres paquetes: @ifc-calc/core (parser + evaluador + generador IFC como biblioteca TypeScript), @openaec/calculations-studio (app de escritorio Tauri 2 con UI en React 19) y @ifc-calc/web (compilación solo para navegador). Multiplataforma: Windows, macOS, Linux.
