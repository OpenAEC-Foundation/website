FAQ

Veelgestelde vragen over open source in de bouw, ons verdienmodel en de toekomst van het ecosysteem.

1Waarom alles open source?

De AEC-sector is een van de laatste grote industrieën die nog volledig draait op gesloten, proprietary software. Dat brengt hoge licentiekosten, vendor lock-in en afhankelijkheid van een handvol leveranciers.

Open source verandert dat fundamenteel:

  • Transparantie — iedereen kan de code inzien, controleren en verbeteren
  • Geen licentiekosten — professionele tools worden toegankelijk voor elk bedrijf, groot of klein
  • Geen vendor lock-in — je data blijft van jou, in open formaten
  • Snellere innovatie — de hele community bouwt mee, niet een enkel bedrijf
  • Toekomstbestendig — software verdwijnt niet als een bedrijf stopt
De gamechanger: agentic coding. Met AI-gestuurde softwareontwikkeling is het intellectueel eigendom (IP) in software geen houdbaar verdienmodel meer. Code kan sneller en goedkoper geschreven worden dan ooit. De waarde zit niet langer in de code zelf, maar in het ecosysteem, de community en de diensten eromheen. Open source is de logische keuze voor de toekomst.
2Blijven de tools altijd gratis?

Ja, alle OpenAEC tools blijven gratis en open source — voor altijd. Dat is geen marketingbelofte, het is een licentiekwestie: alle tools hebben een open source licentie, meestal LGPL-3.0. Die licentie kunnen we niet eenzijdig intrekken. Ook als de stichting morgen stopt of een andere koers kiest, blijft de huidige code voor iedereen vrij beschikbaar.

Wat als de ontwikkeling van één van onze tools stopt?

Dat kan gebeuren — niet elke tool blijft door ons doorontwikkeld. Maar omdat alles open source is, kan iedereen het ontwikkelproject overnemen, forken, of het ideeëngoed in een eigen tool integreren. Een mooi voorbeeld is CalcPAD: de open-source variant van die rekentool werd stopgezet, en wij hebben een belangrijk deel van het ideeëngoed daarvan opgenomen in Open Calculations Studio. Open source garandeert dat goede ideeën niet verloren gaan met een bedrijf.

Geen freemium, geen plotselinge betaalmuur, geen vendor lock-in. Wat vandaag gratis is, is morgen ook gratis. Onze inkomsten halen we uit diensten op het ecosysteem (zie ons verdienmodel) — niet uit het verkopen van licenties.

3Met AI geschreven software is toch van slechte kwaliteit?

We zien dat anders. Wij ontwikkelen alle software binnen OpenAEC met AI-coding — niet als experiment, maar als bewuste werkwijze. Dat verdient uitleg, want het is een nieuwe manier van ontwikkelen die nog wennen is.

Onze stelling: kwaliteit hangt af van hoe je het controleert, niet wie het schrijft. Wij hebben zelf een programmeerachtergrond, maar het grootste deel van wat de AI produceert begrijpen we niet regel-voor-regel. Dat hoeft ook niet. Wat telt is of de uitkomst correct is. Daar sturen wij op met:

  • Verificatieberekeningen — rekentools (Open Calculations Studio, Open Heatloss Studio) worden geijkt tegen referentievoorbeelden uit normen en handboeken. Wijkt iets af, dan klopt het niet.
  • Visuele tests — viewers en grafische tools worden vergeleken met screenshots van gevalideerde uitkomsten.
  • Open source als peer review — al onze code staat publiek op GitHub. Iedereen kan meelezen, fouten vinden en pull requests indienen.
  • Klassieke software-engineering — tests, builds, deploys, semver-versies. Niets anders dan een goed traditioneel team doet.

Traditioneel ontwikkelde software is óók afhankelijk van mensen, en menselijke fouten zijn al decennia de grootste oorzaak van bugs. AI-fouten zijn niet gevaarlijker — ze zijn anders verdeeld. De vangnetten hierboven vangen beide soorten op.

"Maar mensen kunnen de gegenereerde code niet onderhouden" — vandaag (mei 2026) zit daar nog een kern van waarheid in. AI-code is niet altijd zo leesbaar als handgeschreven code. Maar bedenk waar we vandaan komen: begin 2026 was de output significant slechter dan nu. Over een half jaar is er weer een grote stap voorwaarts, en zal onderhoud ook steeds vaker door AI gebeuren — onder onze regie.

Belangrijker nog dan het huidige niveau is de richting van de beweging. Onze stelling — en die is vandaag (mei 2026) bij sommigen nog discutabel — is dat AI-coding over een half tot een jaar niet alleen sneller en goedkoper zal zijn, maar kwalitatief beter dan wat de meeste menselijke ontwikkelaars vandaag schrijven. De richting is onmiskenbaar; alleen het exacte tempo verschilt nog van schatting tot schatting.

"Wat als de AI-leverancier stopt of de prijzen verdrievoudigt?" — geen probleem. We zijn leveranciers-onafhankelijk. Anthropic Claude is onze huidige primaire keuze, maar OpenAI, xAI Grok, Google Gemini, Mistral, DeepSeek en Qwen zijn direct uitwisselbaar. En lokale modellen (Llama, Qwen open-weights) draaien op een gewone GPU. Zelfs bij driedubbele tokenprijzen blijft AI-coding economisch interessanter dan een team fulltime traditionele ontwikkelaars.

De conclusie: AI-coding is geen experiment meer. Meer dan twintig tools, meer dan honderdduizend downloads, supporters die ze in productie gebruiken — allemaal op deze manier gebouwd. We pretenderen niet dat AI-coding zonder discipline kan, maar discipline is geen reden om de techniek af te wijzen. Het is reden om hem te omarmen, met de juiste vangnetten erbij.

4Hoe verdienen jullie geld?

Vooralsnog wordt er veel geïnvesteerd om dit jaar het volledige ecosysteem werkend te krijgen. Alles is en blijft open source. Je kunt alles downloaden via onze GitHub.

Als stichting leveren we diensten rondom het ecosysteem:

  • Consultancy — advies over implementatie, integratie en optimalisatie van de tools binnen jouw organisatie
  • Hosting & SLA — managed hosting van de tools met gegarandeerde uptime en ondersteuning. Vraag een offerte aan voor bijvoorbeeld de BIM Validator
  • Extensions & maatwerk — ontwikkeling van uitbreidingen op de software voor specifieke wensen van opdrachtgevers. De basis blijft open source, de extensie wordt eigendom van de opdrachtgever of wordt bijgedragen aan het ecosysteem
  • AI-ondersteuning op de tools (toekomstig) — premium AI-assistenten ingebed in de tools: automatische rapportage, slimme suggesties bij berekeningen, IFC-extractie via natuurlijke taal, batch-validatie van honderden modellen tegelijk. De tools zelf blijven gratis; de AI-laag is een optionele betaalde dienst voor wie er gebruik van wil maken.
  • Donaties — bedrijven en individuen die de missie steunen
  • Subsidies — overheidssubsidies voor innovatie en digitalisering in de bouw
Doorgaans liggen onze prijzen ca. 20% lager dan de markt doordat er geen kosten voor intellectueel eigendom (IP) in rekening worden gebracht. Je betaalt alleen voor de dienst, niet voor de software.
5Kan ik de tools ook zelf hosten?

Absoluut. Alle tools zijn open source en kunnen zelfstandig geïnstalleerd worden op je eigen server. De meeste tools bieden Docker-images voor eenvoudige deployment. Je hebt volledige controle over je data en infrastructuur.

Als je liever geen beheer wilt, bieden wij managed hosting aan met SLA.

6Op welke technologie zijn de tools gebouwd?

Alle tools in het ecosysteem zijn gebouwd op dezelfde stack: Tauri 2.0 (Rust backend) met een web-frontend. Dit betekent dat elke tool draait als desktop-applicatie (Windows, macOS, Linux), als web-app en als mobiele app — vanuit dezelfde codebase.

Lees meer op onze architectuur pagina.

7Hoe kan ik bijdragen?

Er zijn meerdere manieren om bij te dragen:

  • Code bijdragen — fork een repo op GitHub en dien een pull request in
  • Testen & feedback — gebruik de tools en meld bugs of suggesties
  • Supporter worden — steun de stichting financieel via de supporters pagina
  • Community — volg ons WhatsApp-kanaal
