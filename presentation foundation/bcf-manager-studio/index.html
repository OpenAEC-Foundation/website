Wat is BCF?

BIM Collaboration Format (BCF) is een open standaard (buildingSMART) voor het uitwisselen van issues en opmerkingen tussen BIM-software. Het maakt het mogelijk om problemen in een bouwmodel te melden, bespreken en oplossen — ongeacht welke software de betrokken partijen gebruiken.

  • Open standaard: BCF 2.1 (XML) en BCF API 3.0 (REST)
  • Software-onafhankelijk: werkt met elk BIM-pakket dat BCF ondersteunt
  • Viewpoints: visuele snapshots van het 3D-model bij elke issue
  • Metadata: prioriteit, status, toewijzing, deadlines, labels

Waarom BCF Manager Studio?

Bestaande BCF-tools zijn vaak onderdeel van dure, propriëtaire BIM-platforms. BCF Manager Studio biedt een zelfstandig, open-source alternatief dat iedereen kan gebruiken — gratis, zonder licentiekosten, zonder vendor lock-in.

Het platform draait lokaal of op je eigen server. Je data blijft van jou. Koppel het aan je eigen IFC-viewer, deel issues met je team, en exporteer naar elk BCF-compatibel pakket.

Functionaliteiten

BCF 2.1 issue management

Maak, bewerk en beheer issues conform de BCF 2.1 standaard. Volledige ondersteuning voor topics, comments, viewpoints en snapshots.

Viewpoints met 3D-snapshots

Koppel visuele viewpoints aan issues met camera-positie, selectie en zichtbaarheid. Direct zichtbaar in je IFC-viewer.

Team-samenwerking

Wijs issues toe aan teamleden, stel deadlines in, voeg comments toe en volg de status. Real-time synchronisatie tussen alle deelnemers.

BCF XML import/export

Importeer en exporteer BCF-bestanden (XML-formaat) voor uitwisseling met Solibri, Navisworks, BIMcollab en andere BCF-compatibele software.

REST API (BCF API 3.0)

Volledige BCF API 3.0 implementatie voor integratie met externe tools, dashboards en automatisering.

Projectbeheer

Organiseer issues per project met labels, prioriteiten, milestones en filters. Overzichtelijk dashboard met statistieken.

IFC-koppeling

Koppel issues direct aan IFC-elementen via GlobalId. Navigeer vanuit een issue direct naar het betreffende element in je model.

Self-hosted

Draai het platform op je eigen server of lokaal. Volledige controle over je data, geen cloud-afhankelijkheid.

Notificaties

Ontvang meldingen bij nieuwe issues, statuswijzigingen en reacties. Configureerbaar per project en per gebruiker.

Technologie

Rust TypeScript Tauri 2 BCF 2.1 XML BCF API 3.0 REST API Docker

Gebouwd met dezelfde technologie-stack als het hele OpenAEC-ecosysteem: een Rust-backend voor prestaties en veiligheid, een TypeScript-frontend voor gebruiksvriendelijkheid, en Tauri 2 voor cross-platform distributie.
