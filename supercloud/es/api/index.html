API

Todas las herramientas, también como API

Cada herramienta de la SuperCloud también se puede llamar desde su propio software, para calcular, convertir, comprobar y almacenar. Usted utiliza una sola clave y un lenguaje abierto (IFCX), y paga según el uso.

  • Una clave para todas las herramientas

    Usted crea las claves API en el entorno de administración, por entorno y solo con los permisos necesarios. La misma clave sirve para todas las herramientas.

  • IFCX como entrada y salida

    Las API usan el mismo lenguaje abierto que las apps. Un modelo que usted envía al cálculo de pérdidas de calor pasa sin conversión al cálculo energético.

  • Pago por uso

    Las llamadas cuentan en el consumo de su entorno. Usted fija los límites.

Ejemplo de una llamada

Un cálculo de pérdidas de calor desde su propio script: usted envía un modelo IFCX y recibe el resultado por estancia.

Ejemplo ilustrativo; la especificación definitiva llegará para cada herramienta.

curl -X POST https://demo.cloud.open-aec.eu/api/v1/heatloss/calculations \
  -H "Authorization: Bearer $OPENAEC_API_KEY" \
  -H "Content-Type: application/json" \
  --data @woning.ifcx

# antwoord
{
  "status": "done",
  "standard": "ISSO 51",
  "rooms": 12,
  "design_heat_loss_w": 6420,
  "result": "woning-warmteverlies.ifcx"
}

Cómo funciona

  • AutenticaciónClaves API para scripts e integraciones; OAuth para apps que actúan en nombre de un usuario.
  • EspecificaciónUna especificación OpenAPI pública por herramienta, con ejemplos.
  • LímitesLímites por clave y por entorno, para que un solo script no pueda sobrecargar su entorno.
  • En la UELas llamadas se procesan en la UE, con la misma seguridad que las propias apps.
