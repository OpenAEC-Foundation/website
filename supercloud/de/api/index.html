APIs

Jedes Tool auch als API

Jedes Tool der SuperCloud können Sie auch aus Ihrer eigenen Software aufrufen: rechnen, konvertieren, prüfen und speichern. Mit einem Schlüssel, in einer offenen Sprache (IFCX), und Sie zahlen nach Nutzung.

  • Ein Schlüssel für alle Tools

    API-Schlüssel legen Sie in der Verwaltungsumgebung an, pro Umgebung und nur mit den nötigen Rechten. Derselbe Schlüssel funktioniert für jedes Tool.

  • IFCX rein, IFCX raus

    Die APIs sprechen dieselbe offene Sprache wie die Apps. Ein Modell, das Sie an die Heizlastberechnung senden, geht ohne Konvertierung weiter an die Energieberechnung.

  • Zahlen nach Nutzung

    Aufrufe zählen zum Verbrauch Ihrer Umgebung. Obergrenzen legen Sie selbst fest.

So sieht ein Aufruf aus

Eine Heizlastberechnung aus Ihrem eigenen Skript: Senden Sie ein IFCX-Modell und erhalten Sie das Ergebnis pro Raum zurück.

Beispiel zur Veranschaulichung; die endgültige Spezifikation folgt pro Tool.

curl -X POST https://api.cloud.open-aec.com/v1/heatloss/calculations \
  -H "Authorization: Bearer $OPENAEC_API_KEY" \
  -H "Content-Type: application/json" \
  --data @woning.ifcx

# antwoord
{
  "status": "done",
  "standard": "ISSO 51",
  "rooms": 12,
  "design_heat_loss_w": 6420,
  "result": "woning-warmteverlies.ifcx"
}

  • Open Planner Studio APIProjektplanung und Bauphasen. Verfügbar

  • Open Calculations Studio APIStatische Berechnungen als lesbares Rechenblatt. Verfügbar
  • Open Pointcloud Studio APIPunktwolken ansehen, messen und umwandeln. Verfügbar
  • Monty IFC Viewer APIIFC-Modelle ansehen, auch auf der Baustelle. Verfügbar
  • Open BIM Validator Studio APIIFC-Modelle gegen IDS-Anforderungen prüfen. Verfügbar
  • Open BIM Studio APIBIM-Modelle auf Basis von IFC erstellen und bearbeiten.
  • Open Infra APIBGT-Daten eines Arbeitsgebiets direkt in Ihrer Zeichnung.
  • IfcGit APIVersionsverwaltung für IFC-Modelle.

  • CADCraft APIOpen-Source-2D-Zeichnen und 3D-Modellieren, mit DWG und DXF.

  • Blender + Bonsai APIOpen-Source-BIM-Modellierung in Blender.

So funktioniert es

  • AnmeldungAPI-Schlüssel für Skripte und Anbindungen; OAuth für Apps, die im Namen eines Nutzers arbeiten.
  • SpezifikationPro Tool eine öffentliche OpenAPI-Spezifikation mit Beispielen.
  • GrenzenLimits pro Schlüssel und pro Umgebung, damit ein einzelnes Skript Ihre Umgebung nicht überlastet.
  • In der EUAufrufe werden in der EU verarbeitet, mit derselben Sicherheit wie die Apps selbst.
