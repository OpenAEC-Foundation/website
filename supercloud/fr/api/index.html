API

Tous les outils, aussi en API

Chaque outil du SuperCloud peut aussi être appelé depuis votre propre logiciel, pour calculer, convertir, vérifier et stocker. Vous utilisez une seule clé et un seul langage ouvert (IFCX), et vous payez à l'usage.

  • Une clé pour tous les outils

    Vous créez les clés API dans l'environnement d'administration, par environnement et avec uniquement les droits nécessaires. La même clé fonctionne pour chaque outil.

  • IFCX en entrée et en sortie

    Les API utilisent le même langage ouvert que les applications. Une maquette que vous envoyez au calcul des déperditions passe sans conversion au calcul énergétique.

  • Paiement à l'usage

    Les appels comptent dans la consommation de votre environnement. Vous fixez vous-même les plafonds.

Exemple d'appel

Un calcul des déperditions depuis votre propre script : vous envoyez une maquette IFCX et recevez le résultat par pièce.

Exemple illustratif ; la spécification définitive suivra pour chaque outil.

curl -X POST https://demo.cloud.open-aec.eu/api/v1/heatloss/calculations \
  -H "Authorization: Bearer $OPENAEC_API_KEY" \
  -H "Content-Type: application/json" \
  --data @woning.ifcx

# antwoord
{
  "status": "done",
  "standard": "ISSO 51",
  "rooms": 12,
  "design_heat_loss_w": 6420,
  "result": "woning-warmteverlies.ifcx"
}

Fonctionnement

  • AuthentificationClés API pour les scripts et intégrations ; OAuth pour les applications agissant au nom d'un utilisateur.
  • SpécificationUne spécification OpenAPI publique par outil, avec des exemples.
  • LimitesDes limites par clé et par environnement, pour qu'un script ne puisse pas surcharger votre environnement.
  • Dans l'UELes appels sont traités dans l'UE, avec la même sécurité que les applications elles-mêmes.
