À propos de cette application

Conservez code, scripts et fichiers de projet dans des dépôts Git avec tout leur historique. Travaillez par branches, comparez les versions et fusionnez les modifications, avec n'importe quel client Git courant.

  • Dépôts Git pour le code et les fichiers de projet
  • Historique complet des versions
  • Branches, différences et fusion
  • Compatible avec tout client Git
  • 1 Go de stockage par utilisateur inclus
