À propos de cette application

Modifiez ensemble documents, tableurs et présentations dans le navigateur, dans les formats de fichiers courants. Les fichiers sont stockés dans votre propre environnement.

Le logiciel de bureautique open source sur lequel cela reposera reste à choisir.
