Monty IFC Viewer

OpenAEC · Visualiser des modèles IFC, y compris sur le chantier.

DisponibleAussi disponible séparémentBâtiment

À propos de cette application

Ouvrez un modèle IFC dans le navigateur, sur votre ordinateur portable ou votre tablette. Parcourez le bâtiment, consultez les propriétés et rejouez la séquence de construction.

  • Ouvrir un IFC dans le navigateur
  • Fonctionne sur tablette
  • Propriétés par élément
  • Rejouer la séquence de construction
  • Mesurer dans le modèle
