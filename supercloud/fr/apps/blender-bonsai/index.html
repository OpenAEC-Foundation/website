Blender + Bonsai

Application open source tierce · Blender en IfcOpenShell · Modélisation BIM open source dans Blender.

S'inscrire avec cette applicationCommencez gratuitement et activez cette application quand vous le souhaitez.

Application open source tierce, hébergée ou connectée par OpenAEC. Ses créateurs ne sont pas liés à OpenAEC.

À propos de cette application

Bonsai fait de Blender un environnement BIM complet qui travaille directement en IFC. Avec le module complémentaire OpenAEC, vous ouvrez et enregistrez vos modèles dans votre propre environnement, avec versions et verrouillage.

Plus tard, aussi comme poste de travail cloud dans le navigateur.

  • Modélisation BIM en IFC
  • Module complémentaire OpenAEC pour vos fichiers
