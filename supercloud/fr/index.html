Quatre engagements

Ce que défend le SuperCloud

{ }

Open source, sans dépendance fournisseur

  • Tout le code source est public
  • Export complet à tout moment
  • Aussi sur vos propres serveurs
  • Résiliable chaque mois
1×

Simple à utiliser

  • Un seul compte pour toutes les applications
  • La même interface et la même identité visuelle partout
  • Dans le navigateur et en application de bureau
  • Activez et désactivez vous-même les applications
IFCX

Outils interconnectés

  • Un langage ouvert pour nos outils : IFCX
  • Fondé sur la norme ouverte IFC
  • 2D, 3D, SIG et calculs dans une seule maquette
  • Nous connectons les autres applications à cette maquette
AI

IA avec des modèles dans l'UE

  • Par défaut, uniquement des modèles hébergés dans l'UE
  • Vos données ne sont pas utilisées pour l'entraînement
  • L'IA ne recherche que dans les contenus que vous êtes autorisé à ouvrir
  • Par exemple : « Quels avis de fondation avons-nous donnés à Dordrecht depuis 2022 ? »

Aussi disponible séparément

Ne prenez que ce dont vous avez besoin

Il n'est pas nécessaire de faire migrer toute l'entreprise en une fois. Commencez par un seul élément, sans environnement d'entreprise.

  • Open Office Studio

    Modifier ensemble documents, tableurs et présentations dans le navigateur.

  • Speckle

    Partager des modèles 3D entre logiciels de conception, dans votre propre environnement.

  • Outils dans le navigateur

    Open PDF Studio, Open Calc Studio et des visionneuses dans le navigateur, avec un compte personnel.

  • IA traitée dans l'UE

    Crédit pour les fonctions d'IA des applications, par défaut uniquement via des modèles situés dans l'UE.

Aussi sur vos propres serveurs
