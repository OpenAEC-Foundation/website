Questions sur le SuperCloud

Vous trouverez ci-dessous les réponses aux questions qui nous sont le plus souvent posées.

Qu'est-ce qu'IFCX ?

IFCX est le langage de données ouvert commun à toutes les applications OpenAEC. IFCX s'appuie sur IFC, la norme ouverte des maquettes numériques, et y ajoute les plans 2D, le SIG, les calculs et les annotations. Chaque application travaille ainsi sur la même maquette, sans aucune conversion.

Combien coûte le SuperCloud ?

Vous composez votre abonnement à partir de briques, avec un prix par utilisateur et par mois. L'hébergement en Europe, le chiffrement avec votre propre clé et les sauvegardes sont inclus ; vous choisissez vous-même le niveau de service. Les applications sont soumises à une contribution fixe au développement continu. Nous publions la composition des prix et les révisons tous les six mois.

Existe-t-il une version gratuite ?

Oui. Avec un compte personnel gratuit, vous pouvez utiliser les outils dans le navigateur, avec un espace de stockage limité. Un environnement d'entreprise démarre après le premier paiement et est résiliable chaque mois.

Où sont stockées mes données ?

Dans un centre de données de l'Union européenne, dans un environnement isolé propre à chaque client, chiffré avec sa propre clé. Les sauvegardes sont conservées dans une deuxième région de l'UE.

Puis-je n'utiliser qu'un seul élément ?

Oui. Vous pouvez par exemple utiliser uniquement OpenAEC Storage pour partager et envoyer des fichiers, ou uniquement les outils dans le navigateur, sans environnement d'entreprise complet.

Le SuperCloud peut-il aussi fonctionner sur nos propres serveurs ?

Oui. Toutes les applications sont open source et peuvent aussi fonctionner en on-premise, dans votre propre salle serveur ou chez votre propre hébergeur. OpenAEC Studio BV vous accompagne pour l'installation, la gestion et les mises à jour.

Pouvons-nous reprendre nos fichiers et nos données administratives actuels ?

Oui. OpenAEC Studio BV accompagne la migration depuis des logiciels fermés, pour l'e-mail, les fichiers et les données administratives. Après votre inscription, vous indiquez que vous souhaitez être accompagné pour la migration.

Le SuperCloud est-il compatible avec les fichiers de nos partenaires ?

Les applications prennent en charge les formats ouverts courants, comme IFC pour les maquettes numériques, DWG et DXF pour les plans, et PDF. La page de chaque application indique ce que cette application prend en charge.

Que se passe-t-il si nous voulons arrêter ?

Vous pouvez tout exporter à tout moment. Après la résiliation, vous disposez de 30 jours d'accès en lecture seule pour tout récupérer. Votre environnement est ensuite gelé, puis supprimé, avec une attestation de suppression.

Tous les logiciels sont-ils open source ?

Les outils développés par OpenAEC et les applications tierces sont open source. Certains de nos outils se trouvent encore dans un dépôt privé tant que leur développement est en cours ; leur page indique alors « Sera rendu public ». Pour les autres applications, vous trouverez le lien vers le code source.

Quelle est la différence entre l'OpenAEC Foundation et OpenAEC Studio BV ?

L'OpenAEC Foundation (en création) développe et coordonne les logiciels open source. OpenAEC Studio BV propose le SuperCloud et fournit des services tels que la mise en œuvre, la migration, le support et le développement sur mesure.

Votre question n'y figure pas ?

Créez un compte gratuit et essayez le SuperCloud par vous-même, ou informez-vous sur la sécurité et la confidentialité.
