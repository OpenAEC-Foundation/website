OpenAEC · View and classify cone penetration tests and boreholes.

AvailableGeotechnics

About this app

Load cone penetration tests and borehole logs, classify the soil layers and lay everything out on a site plan.

Works with the same file formats as the Dutch national subsurface register.

  • Load GEF and BRO files
  • Robertson classification
  • Site plan with test locations
  • Report as PDF
  • Export to IFCX
