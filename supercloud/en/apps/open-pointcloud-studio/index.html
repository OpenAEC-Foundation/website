Open Pointcloud Studio

OpenAEC · View, measure and convert point clouds.

AvailableGeneral
Sign up with this appSwitch this app on in your environment whenever it suits you.

About this app

Load large point clouds from scans, measure distances and create sections. Convert the point cloud to a mesh or to 2D underlays for your drawing.

  • Smooth viewing of large point clouds
  • Measure distances and heights
  • Create sections
  • Convert to mesh
  • Export to 2D
