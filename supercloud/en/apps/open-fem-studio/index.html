Open FEM Studio

OpenAEC · Analyse structures with finite elements.

AvailableBuildings
Sign up with this appSwitch this app on in your environment whenever it suits you.

About this app

Calculate forces, moments and deflections of 2D and 3D structures using the finite element method and check the results against the design codes.

  • Frames in 2D and 3D
  • Loads and combinations
  • Forces, moments and deflections
  • Code checks
  • Report as PDF
