About this app

CADCraft is an open-source CAD program in Rust by the ArtCraft team: command-line drafting with layers, blocks, dimensions and layouts, complemented by a 3D tab for solids. The program opens and saves DWG and DXF through the Rust library acadrust, to which OpenAEC developers contribute.

  • Drafting with layers, blocks, dimensions and hatches
  • Read and write DWG via acadrust
  • Read and write DXF
  • Plot to PDF, export to SVG and PNG
  • Can be controlled by AI agents (MCP)
