API's

Alle tools ook als API

Elke tool op de SuperCloud is ook vanuit uw eigen software aan te roepen, voor rekenen, omzetten, controleren en opslaan. U gebruikt één sleutel en één open taal (IFCX), en betaalt naar gebruik.

  • Eén sleutel voor alle tools

    U maakt API-sleutels aan in de beheeromgeving, per omgeving en met alleen de rechten die nodig zijn. Dezelfde sleutel werkt voor elke tool.

  • IFCX als invoer en uitvoer

    De API's gebruiken dezelfde open taal als de apps. Een model dat u naar de warmteverliesberekening stuurt, gaat zonder conversie door naar de energieberekening.

  • Betalen naar gebruik

    Aanroepen tellen mee in het verbruik van uw omgeving. U stelt zelf plafonds in.

Voorbeeld van een aanroep

Een warmteverliesberekening vanuit uw eigen script: u stuurt een IFCX-model op en krijgt de uitkomst per vertrek terug.

Illustratief voorbeeld; de definitieve specificatie volgt per tool.

curl -X POST https://demo.cloud.open-aec.eu/api/v1/heatloss/calculations \
  -H "Authorization: Bearer $OPENAEC_API_KEY" \
  -H "Content-Type: application/json" \
  --data @woning.ifcx

# antwoord
{
  "status": "done",
  "standard": "ISSO 51",
  "rooms": 12,
  "design_heat_loss_w": 6420,
  "result": "woning-warmteverlies.ifcx"
}

Hoe het werkt

  • AuthenticatieAPI-sleutels voor scripts en koppelingen; OAuth voor apps die namens een gebruiker werken.
  • SpecificatiePer tool een openbare OpenAPI-specificatie, met voorbeelden.
  • GrenzenLimieten per sleutel en per omgeving, zodat één script uw omgeving niet kan overbelasten.
  • In de EUAanroepen worden in de EU verwerkt, met dezelfde beveiliging als de apps zelf.
