Documentbeheer · prototype

OpenAEC Docs

Projectdocumenten van BIM-projecten op één plek

Een prototype van een documentbeheersysteem voor BIM-projecten: een server in Rust en een webinterface in React, bovenop Nextcloud. Per project vaste mappen, een manifest van de modellen en issuesets die erbij horen, en inloggen via OIDC. De ontwikkeling ligt sinds april 2026 stil.

Broncode Docker Compose Naar de SuperCloud
  • Prototype · stilgevallen
  • Nextcloud · PostgreSQL
  • Zelf hosten met Docker
  • Openbare broncode

Stilgevallen prototype. Sinds april 2026 is er niet meer aan OpenAEC Docs gewerkt. Er zijn geen releases, geen gehoste versie en geen installatiehandleiding; de broncode staat openbaar op GitHub, nog zonder licentie.

Functies

Wat het prototype kan

Begin bij de hoogtepunten of kies een onderwerp.

01 Bestanden

Projectbestanden rechtstreeks in Nextcloud

Upload, open en verwijder bestanden en maak mappen, per project. De bestanden staan in een projectmap op Nextcloud; de server praat daar via WebDAV mee en houdt de metadata bij in PostgreSQL.

02 Projecten

Vaste projectmappen

Per project een vaste indeling, zoals modellen, tekeningen, berekeningen en rapporten, met per map de toegestane bestandstypen. Een bestaande Nextcloud-projectmap kun je koppelen in plaats van een nieuwe te maken.

03 Manifest

Wat bij een project hoort

Een project kan meerdere manifesten hebben die bijhouden welke IFC-modellen, issuesets en rapporten erbij horen, zodat andere OpenAEC-tools ze vinden. De projectweergave toont ze in een zijpaneel.

04 Koppelingen

Inloggen, organisaties en koppelingen

Inloggen via single sign-on (OIDC), met meerdere organisaties op één installatie, elk met een eigen Nextcloud. Koppelingen met de BIM Validator en het BCF-platform van OpenAEC, en alles via een REST API.

Veelgestelde vragen

Wordt er nog aan OpenAEC Docs gewerkt?

Nee, niet op dit moment. De laatste wijziging is van april 2026 en de app staat niet meer in het overzicht op de homepage. Voor projectbestanden in de cloud werkt OpenAEC nu aan de SuperCloud.

Kan ik het uitproberen?

Er is geen gehoste versie en geen release. Wie het wil proberen, kan de broncode van GitHub zelf bouwen en draaien met Docker Compose; je hebt dan ook een Nextcloud, een PostgreSQL-database en een OIDC-aanbieder nodig.

Wat is een documentbeheersysteem voor BIM-projecten?

Eén plek waar alle documenten van een project staan, van modellen en tekeningen tot berekeningen en rapporten, met een vaste mapindeling en afspraken over wat waar hoort. OpenAEC Docs voegt daar een manifest aan toe, zodat ook andere tools weten welke modellen en issuesets bij een project horen.

Waarom Nextcloud?

Nextcloud is open source en kun je zelf hosten, dus de bestanden blijven op een server die je zelf kiest. OpenAEC Docs bewaart de bestanden zelf in Nextcloud en alleen de administratie in een eigen database.

Hoe verhoudt het zich tot de SuperCloud?

Het zijn aparte projecten. OpenAEC Docs bouwde op Nextcloud en de bibliotheek openaec-cloud; de SuperCloud heeft een eigen opslagserver met ruimtes, versies en een desktop-app om te synchroniseren.

Onder welke licentie valt de code?

De broncode staat openbaar op GitHub, maar er staat nog geen licentie bij. Wil je er iets mee doen, neem dan contact op via info@open-aec.com.
