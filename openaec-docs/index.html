OpenAEC Ecosysteem

OpenAEC Docs

Open source BIM document management platform. Beheer, deel en archiveer alle projectdocumenten op een centrale plek.

Beta

Wat is OpenAEC Docs?

OpenAEC Docs is een document management systeem (DMS) speciaal ontworpen voor BIM-projecten in de AEC-sector. Het is gebaseerd op Nextcloud — het populairste open source platform voor bestandsbeheer en samenwerking. Het biedt een centrale plek voor het beheren, delen en archiveren van alle projectdocumenten — van tekeningen en rapporten tot contracten en vergunningen.

Gebouwd op Nextcloud met aanvullende Rust en TypeScript modules voor BIM-specifieke functionaliteit.

Nextcloud Rust TypeScript Docker PostgreSQL

Functionaliteiten

Documentbeheer

Upload, organiseer en doorzoek documenten per project, discipline of fase. Automatische metadata-extractie.

Versiebeheer

Volledige versiegeschiedenis van elk document. Vergelijk versies en herstel eerdere revisies.

IFCX-koppeling

Documenten koppelen aan IFCX-modelelementen. Bekijk gerelateerde documenten direct vanuit het BIM-model.

Toegangscontrole

Rol-gebaseerde rechten per project en map. Bepaal wie documenten mag bekijken, bewerken of verwijderen.

Zoeken & filteren

Full-text zoeken door documenten en metadata. Filter op type, datum, auteur of status.

API & integratie

REST API voor integratie met andere tools in het OpenAEC-ecosysteem. Webhooks voor automatisering.

Self-hosted & privacy-first

OpenAEC Docs draait op je eigen server via Docker. Volledige controle over je data, geen cloud-afhankelijkheid. Ideaal voor organisaties met strenge privacy- en compliance-eisen.
