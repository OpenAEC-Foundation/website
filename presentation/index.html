The connection

One open language: IFCX

Drawings, models and calculations in the same open format, plainly readable.

{
  "header": {
    "ifcxVersion": "ifcx_alpha",
    "author": "OpenAEC"
  },
  "data": [
    {
      "path": "/cad/d1/layout/1",
      "children": { "0": "/cad/d1/e1" },
      "attributes": {
        "ifccad::layout": {
          "kind": "Model"
        }
      }
    }
  ]
}
