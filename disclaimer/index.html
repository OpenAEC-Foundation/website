Disclaimer

Juridische informatie over de OpenAEC Foundation en het gebruik van onze software.

Stichting

De OpenAEC Foundation (Stichting OpenAEC Foundation) is gevestigd in Nederland en valt onder het Nederlands recht. De stichting heeft geen winstoogmerk.

Open source licenties

Alle software van de OpenAEC Foundation wordt uitgebracht onder erkende open source licenties (MIT, LGPL, CC BY-SA). Raadpleeg de individuele repositories op GitHub voor de specifieke licentie per project.

Clean Room Declaration

Voor zover de OpenAEC Foundation software ontwikkelt die interopereert met gesloten (proprietary) bestandsformaten, geschiedt dit uitsluitend op basis van clean room reverse engineering conform de Europese Softwarerichtlijn (Richtlijn 2009/24/EG).

Er wordt geen gebruik gemaakt van beschermde broncode, vertrouwelijke documentatie of gelekte informatie van derden. Alle implementaties zijn gebaseerd op publiek beschikbare specificaties, eigen analyse en onafhankelijk onderzoek.

Privacy

De OpenAEC Foundation verzamelt geen persoonlijke gegevens via haar tools. Tools die lokaal draaien verwerken alle data op uw eigen apparaat. Voor hosted diensten geldt ons privacybeleid.

Aansprakelijkheid

De software wordt geleverd "as is", zonder enige garantie. De OpenAEC Foundation is niet aansprakelijk voor schade die voortvloeit uit het gebruik van de software. Zie de specifieke open source licentie per project voor de volledige disclaimerbepalingen.

Concept statuten

De conceptstatuten van de stichting zijn beschikbaar op onze website. Bekijk de concept statuten.
