Python library

Building.py

A Python library for creating buildings, building systems, and objects. Export to Speckle, FreeCAD, Revit, IFC, Struct4U, and more. Pure Python geometry creation without dependencies.

Download bp_single_file.py (486 KB) View source

v0.1-beta — Requires Python 3.10 or higher

Why building.py?

In building design, almost everything can be categorized as a beam or a panel — from windows and curtain walls to floor systems. Building.py automates the creation of these systems with a pure Python library that has no external dependencies.

Export targets

Speckle

Export geometry and objects to the Speckle platform for collaboration and data exchange.

FreeCAD

Generate FreeCAD-compatible geometry for further 3D modeling.

IFC (via IfcOpenShell)

Export to Industry Foundation Classes format using IfcOpenShell.

Struct4U / XFEM4U

Export structural models for analysis in Struct4U and XFEM4U.

Scia Engineer

Export to Scia Engineer for structural calculation.

Geometry and objects

Primitives

Point, Line, Arc, PolyCurve, Mesh, Extrusion, Text, with Vector, Plane, Matrix, and Color abstractions.

Building objects

Beam, Panel, Dimension, Tag, Hatch — the core building blocks for parametric construction models.

Steel profiles library

Built-in library of standard steel cross-sections for structural design.

Pattern systems

Generate brick bond patterns (stretcher bond, cross bond) with configurable dimensions and joints. PAT file export.

Import capabilities

Images

Image import support (50% complete).

CityJSON

CityJSON import for urban-scale 3D city models (50% complete).
