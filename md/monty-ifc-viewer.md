## Key features

- IFC 2x3 / IFC 4 / IFC 4.3 viewing
- Property inspection
- Spatial structure tree
- Section and isolate tools
- Fast load times

## Tech stack

`Rust` · `WebGPU` · `Tauri 2` · `IfcOpenShell`

## When to use this

Quick BIM model spot-checks without launching a full authoring tool, viewing IFCs sent by partners.

## Alternative to

- Solibri Anywhere
- BIMvision
- Tekla BIMsight
- usBIM.viewer+

## Standards & integration

- IFC 2x3
- IFC 4
- IFC 4.3

All OpenAEC tools exchange data via the open **IFCX** format (based on IFC 4.3).
