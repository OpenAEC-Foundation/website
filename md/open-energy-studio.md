## Key features

- NTA 8800 energy performance calculation
- BENG indicator output (BENG 1/2/3)
- IFCX-based building data input
- PDF report generation

## Tech stack

`Rust` · `TypeScript` · `Tauri 2`

## When to use this

Computing BENG indicators and energy labels for buildings in the Netherlands, comparing energy concepts during design.
