## Key features

- Defect pinning on PDF or image floorplans
- NEN 2767 condition assessment checklists
- Photo capture and annotation
- Offline-first sync
- BCF export for issue handover

## Tech stack

`Rust` · `TypeScript` · `Tauri 2`

## When to use this

On-site inspections, snagging, NEN 2767 condition assessment, quality control with offline mobile use.

## Alternative to

- PlanRadar
- Snagar
- Fieldwire

## Standards & integration

- NEN 2767
- BCF 2.1

All OpenAEC tools exchange data via the open **IFCX** format (based on IFC 4.3).
