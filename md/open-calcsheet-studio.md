## Key features

- Calculation sheets written as text, worked out with units and readable formulas while you type
- Spreadsheet (.xlsx), formula canvas, node graph (reads .dyn), drawing sheet A4 to A2, Jupyter, Marimo, Markdown and PDF sheets in one project
- One continuous report with cover, table of contents and page numbers, in your own house style
- Modules with an input screen: timber joist floor, beam in timber or steel, two-pile cap, to the Eurocodes with the Dutch national annex
- 137 formulas to insert and 15 worked examples; online module library
- IFCX project file, IFC4x3 export, opens calculation text (.cpd), DXF to a drawing in a sheet
- MCP server and REST API with 43 tools on 127.0.0.1, behind a token

## Tech stack

`TypeScript` · `Rust` · `Tauri 2` · `React` · `CodeMirror` · `KaTeX` · `mathjs` · `JupyterLite`

## When to use this

Structural calculations that a reviewer must be able to follow step by step and that have to end up in one report.

## Alternative to

- hand calculations in a spreadsheet
- commercial calculation sheet software

## Standards & integration

- EN 1995-1-1
- EN 1993-1-1
- EN 1992-1-1
- IFC4x3

All OpenAEC tools exchange data via the open **IFCX** format (based on IFC 4.3).
