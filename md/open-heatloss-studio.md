## Key features

- Room-by-room transmission heat loss (NEN 12831)
- Ventilation heat loss
- U-value catalog and editor
- Climate data per municipality (ISSO 51:2023)
- IFCX building geometry input
- PDF report export
- Temperature factor checks

## Tech stack

`Rust` · `TypeScript` · `Tauri 2`

## When to use this

Sizing radiators and floor heating per NEN 12831, ISSO 51:2023 compliance reporting, Dutch building permit submissions.
