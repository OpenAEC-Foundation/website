## Key features

- LAS and LAZ format support
- RGB, elevation and classification colouring
- Eye-Dome Lighting (EDL)
- Octree level-of-detail for very large clouds
- Cross-section and measurement tools

## Tech stack

`Rust` · `WebGPU` · `Tauri 2`

## When to use this

Inspecting laser-scanned site captures, comparing scans against BIM, lightweight viewing without CloudCompare or ReCap.

## Alternative to

- CloudCompare
- Potree Desktop
- Autodesk ReCap

## Standards & integration

- LAS
- LAZ

All OpenAEC tools exchange data via the open **IFCX** format (based on IFC 4.3).
