Hoe we bouwen

Eén codebase, overal

Elke tool is één programma dat op elk platform draait. Rust is het uitgangspunt; de rest volgt uit wat de tool nodig heeft.

Architectuur

Rust

Rekenkern en interface in Rust, als één native programma. Snel, weinig geheugen, voor zware grafische tools.

Voorbeeld: Open CAD Studio

Tauri

Een Rust-kern met een interface in TypeScript. Dezelfde interface draait als desktop-app en in de browser.

Voorbeeld: Open PDF Studio

DynLex

Onze eigen programmeertaal. Leest bijna als Engelse zinnen en compileert via LLVM naar native code.

Voorbeeld: Open BIM Studio

Web

Dezelfde code in de browser, via WebAssembly of als web-app. Niets installeren.

Voorbeeld: Probeer online

Zowel lokaal op Windows, macOS en Linux (Ubuntu, Fedora) als webbased in de browser. Geen aparte versies, geen dubbel onderhoud.
