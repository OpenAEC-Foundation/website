Pioniers — Personen

De mensen die de moed hadden om anders te denken. Die hun werk weggaven zodat de wereld er beter van werd.

Linus Torvalds 🇫🇮

Creator Linux kernel & Git
"Talk is cheap. Show me the code."

De man die het besturingssysteem van de wereld bouwde als hobbyproject, en later Git creeerde om de samenwerking van duizenden developers mogelijk te maken.

Guido van Rossum 🇳🇱

Creator Python
"Beautiful is better than ugly. Simple is better than complex."

De Nederlander die de meest populaire programmeertaal ter wereld creeerde. Python is de taal van AI, wetenschap en het web.

LinkedIn

Ton Roosendaal 🇳🇱

Creator Blender, Blender Foundation

In 2002 crowdfunding van €100.000 in 7 weken om Blender vrij te kopen van het failliete NaN Technologies. Vandaag is Blender de industrie-standaard voor 3D creatie.

LinkedIn

Thomas Krijnen 🇳🇱

Creator IfcOpenShell, AECgeeks

De man achter de open BIM revolutie. IfcOpenShell is de ruggengraat van open source BIM-tools en maakt het mogelijk om IFC-bestanden te lezen, schrijven en manipuleren.

LinkedIn

Dion Moult 🇦🇺

Lead developer Bonsai (BlenderBIM), IfcOpenShell contributor

Pionier in open source BIM tools. Bonsai maakt het mogelijk om volwaardige BIM-modellen te maken in Blender, volledig open source.

LinkedIn

Mark Shuttleworth 🇿🇦

Founder Ubuntu/Canonical
"Computer is not a device anymore. It is an extension of your mind."

Eerste Afrikaan in de ruimte. Stichtte Canonical en maakte Linux toegankelijk voor iedereen met Ubuntu.

LinkedIn

Rushabh Mehta 🇮🇳

Founder ERPNext/Frappe

Open source ERP dat SAP uitdaagt. Frappe Framework en ERPNext bewijzen dat enterprise software niet duur en gesloten hoeft te zijn.

LinkedIn

Antonio González Viegas 🇪🇸

Founder That Open Company (IFC.js)

"An architect who started coding" — bracht open BIM naar het web. That Open Company maakt het mogelijk om IFC-modellen direct in de browser te bekijken en bewerken.

LinkedIn

Richard Stallman 🇺🇸

Founder GNU Project & Free Software Foundation (1983)
"Free software is a matter of liberty, not price."

De godfather van vrije software. Zonder GNU en de GPL was er geen open source beweging zoals we die kennen.

Dennis Ritchie 🇺🇸 †2011

Creator C & mede-creator UNIX

Zonder C en UNIX was er geen Linux, geen Python, geen internet zoals we het kennen. De stille held wiens werk letterlijk alles mogelijk maakte.

Graydon Hoare 🇨🇦

Creator Rust programmeertaal (bij Mozilla)

Rust: de taal waar OpenAEC op gebouwd is. Veiligheid, snelheid en betrouwbaarheid zonder concessies.

Solomon Hykes 🇫🇷

Creator Docker

Revolutioneerde software deployment met containers. Docker maakte het mogelijk om software overal identiek te draaien.

Frank Karlitschek 🇩🇪

Founder Nextcloud

Open source alternatief voor cloud storage. Nextcloud geeft gebruikers controle terug over hun eigen data.

Open Source Projecten

De tools en frameworks waarop OpenAEC is gebouwd. Elk project vertegenwoordigt jaren van onbetaald werk door gepassioneerde developers.

Linux

Het besturingssysteem dat de wereld draait. Van servers tot smartphones.

Python

De taal die iedereen kan leren. Van scripting tot machine learning.

Blender

3D creatie voor iedereen. Modellering, animatie, rendering en meer.

IfcOpenShell

De ruggengraat van open BIM. Lezen, schrijven en manipuleren van IFC-bestanden.

Bonsai (BlenderBIM)

BIM modelleren in Blender. Volwaardige BIM-authoring, volledig open source.

That Open Company

Open BIM op het web. IFC-modellen bekijken en bewerken in de browser.

ERPNext / Frappe

Open source ERP. Boekhouding, projectmanagement, CRM en meer.

Nextcloud

Bestandsbeheer en samenwerking. Jouw data, jouw server, jouw regels.

Docker

Containers voor deployment. Software overal identiek laten draaien.

Rust

Veilige systeemprogrammeertaal. Snelheid zonder concessies aan veiligheid.

LibreOffice

Vrije kantoorapplicaties. Documenten, spreadsheets en presentaties voor iedereen.

Ubuntu

Linux voor iedereen. Het besturingssysteem dat Linux naar de desktop bracht.

Git

Versiebeheer voor de wereld. Samenwerken aan code op globale schaal.

Three.js

3D graphics op het web. De basis voor interactieve 3D-ervaringen in de browser.

PDF.js

PDF rendering in de browser. Open source alternatief voor proprietary PDF-viewers.

Tauri

Lichtgewicht desktop apps. Webtech met native performance en kleine bundles.

Wij staan op de schouders van reuzen. Elke regel code die wij schrijven is mogelijk gemaakt door de moed van deze pioniers. Open source is geen trend — het is de toekomst.
