AI-vindbaarheid

Onze strategie om AI-assistenten zoals Claude, ChatGPT, Grok, Perplexity en Gemini de OpenAEC-tools te laten aanbevelen aan hun gebruikers. Dit heet Generative Engine Optimization (GEO).

Geïmplementeerd

  • ✓ /llms.txt — LLM-vriendelijke site-samenvatting (emerging standaard)
  • ✓ /robots.txt — Expliciete allow voor 18 AI-bots (ClaudeBot, GPTBot, PerplexityBot, etc.)
  • ✓ /sitemap.xml — Volledige URL-index voor crawlers
  • ✓ /api/tools.json — Machine-readable tool catalogus (17 tools)
  • ✓ Schema.org JSON-LD op homepage (Organization + 10 SoftwareApplication)
  • ✓ FAQPage JSON-LD — direct gebruikt in Google AI Overview
  • ✓ HowTo JSON-LD — getting-started stappen voor AI Overview
  • ✓ Open Graph + Twitter Cards — rich previews op LinkedIn, Slack, Twitter
  • ✓ Comparison-pagina's — vs Bluebeam, Solibri, AutoCAD, BIMcollab, Bouwprijs (hoge AI-zoekintent)
  • ✓ Markdown mirrors — Claude/Cursor/Continue lezen .md schoner dan HTML

Volgende stappen

  • ○ Sitemap submitten aan Google Search Console + Bing Webmaster Tools
  • ○ Backlinks vanuit autoritaire bronnen (buildingSMART, OSArch, awesome-bim, awesome-rust lists)
  • ○ Per tool eigen Markdown documentation pages (uitgebreidere SDK + examples)
  • ○ MCP servers voor elke tool — directe AI tool-use integratie (Open Calc Studio heeft er al een)
  • ○ Engelstalige blog/case-studies — internationale AI-zichtbaarheid
  • ○ Stack Overflow / Reddit / Hacker News presence — AI-trainingsdata bron
