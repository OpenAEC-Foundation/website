Neden Open Calculations Studio?

CalcPAD yıllardır Hollandalı yapı mühendisleri tarafından el hesaplamaları için kullanılıyor. Ama kapalı kaynak, sadece Windows'ta çalışır ve yerleşik BIM entegrasyonu yoktur. CalcPAD · IFC4x3 · IFCX

Open Calculations Studio nedir?

Open Calculations Studio, yapısal hesaplamalar için modern bir açık kaynak araçtır — CalcPAD'den ilham alarak, Hollandalı ve Avrupalı yapı mühendisleri arasında yaygın olarak kullanılan araç. Tüm hesaplama motorunu CalcPAD syntax desteği ile TypeScript'te yeniden inşa ettik ve hesaplamaların doğrudan BIM modelleriyle entegre olması için canlı IFC ve IFCX dışa aktarımı ekledik.

  • CalcPAD uyumlu Mevcut .cpd dosyaları değişiklik gerektirmeden çalışır

  • Birim farkındalıklı Mathjs ile mm, kN, N/mm², mm⁴

  • Canlı IFCX + IFC4x3 STEP dışa aktarımı Hesap doğrudan BIM elemanına dönüşür

  • KaTeX ile görüntüleme Gerçek kesirler, alt/üst simgeler ve Yunan harfleriyle matematiksel formüller

  • SVG çizimler Parametrik şemalar doğrudan hesabın içinde

  • Yük durumları Ayrı sekmelerde SLS / ULS / deprem

  • Kütüphane olarak kullanılabilir FEM uygulamalarına veya yönetmelik kontrollerine gömülebilir

Örnek belge

Bir CalcPAD belgesi bir mühendis için doğal hissettirir — formüller, birimler, koşullu mantık ve çizimler yan yana:

woning-laageind-57.cpd
"Project — woning Laageind 57

#include svg_drawing.cpd

# 1. Invoer
b = 300 mm
h = 500 mm
N_Ed = ?*(kN)
fck = 30 N/mm^2

# 2. Geometrie
A = b*h          // mm² — automatisch
W_y = b*h^2/6    // mm³

# 3. Toetsing
sigma = N_Ed/A to N/mm^2

#if sigma ≤ fck/1.5
    'Voldoet ✓
#else
    'Voldoet NIET ✗
#end if

# 4. Detail-tekening
@img(detail-D1.svg)

# 5. Belasting-diagram
$Plot{f(x) @ x = 0 : L}

Özellikler

Birimli formüller

mm, kN, N/mm², mm⁴ ve tüm SI birimleriyle çalışın. Mathjs birim-farkında aritmetik ve otomatik basitleştirme (b*h → mm²) sağlar.

Matematiksel dizgi

Gerçek kesirler, üstler, altlar ve Yunan harfleri (σ, ε, ρ, Φ, ψ) ile KaTeX render. Formüller isim = formül = doldurulmuş değerler = sonuç'u tek satırda gösterir.

Canlı önizleme

.cpd için sözdizimi vurgulamalı split-pane editör (CodeMirror 6). Yazarken debounced önizleme yeniden render eder.

Yük durumları

SLS / ULS / deprem vb. için sekmeler, her biri kendi giriş değişkeni prompt değerleri ile. Tek belge, birden fazla senaryo.

CalcPAD uyumlu

Mevcut .cpd dosyalarıyla tamamen uyumlu: #if/#else if/#end if, #repeat, #for, #def makroları, #include, $Plot, matrisler, lookuplar.

IFC4x3 STEP dışa aktarma

Geleneksel değişken isimleri (b_fdn, l_fdn, D_paal, M_Ed, R_c_d) aracılığıyla yapısal elemanları algılar. Geçerli Project → Site → Building → Storey iskeleti oluşturur.

IFCX JSON-LD

Canlı IFCX (draft) dışa aktarma — hesaplamalar, standartlar ve meta veriler için ad alanları olan IFC'nin yeni nesli. Hesaplama ve BIM modeli tek formatta.

SVG çizimleri

Değer interpolasyonu ile parametrik SVG makroları. @img(file.svg) dış çizimleri satır içinde gömer. Elle yazılmış SVG için @svg ... @end.

IFC sekmesi

Sözdizimi vurgulamalı yerleşik STEP görüntüleyici ve IFCX JSON görüntüleyici. Tıklanabilir entity türleri doğrudan buildingSMART belgelerine bağlanır.

GEF yükleme

@gef name yükleme — temel hesaplamalarında doğrudan sondaj verilerini kullanın. Open Geotechniek Studio ile entegre olur.

5 tema

Light, Forge, OpenAEC, Blueprint ve Contrast — tümü OpenAEC tasarım token'ları üzerine inşa edilmiştir. Ortamınız için en iyi çalışanı seçin.

PDF dışa aktarma

Headless önizleme ile Tauri shell aracılığıyla baskıya hazır PDF dışa aktarma. Proje dosyası veya üçüncü taraf incelemesi için hazır.

Kütüphane modu

@ifc-calc/core'u TypeScript kütüphanesi olarak kullanın: FEM uygulamalarından veya code-checking'den ayrıştırın, değerlendirin, render edin, IFC/IFCX oluşturun.

.cpd

CalcPAD uyumluluğu

Gerçek dünya CalcPAD dosyalarıyla tamamen subset compatible. Mevcut .cpd belgelerinizde out-of-the-box çalışır:

  • "Title, 'prose, // comment

  • #if … #else if … #else … #end if, #hide / #show / #pre / #post

  • #repeat n … #end repeat en #for var = lo : hi … #loop (incl. nested)

  • #def name(p1; p2; …) … #end def macros, #def Name$ = literal constants

  • #include filename.cpd — externe macro-libraries en SVG drawings

  • $Plot{ … @ x = lo : hi } — inline parametrische plots

  • Subscript-comma's (V_b,0), $-getypeerde refs, matrix [a;b|c;d]

  • Format-specs (:F2), dotted/percent identifiers

  • mathjs Matrix-aware take, hlookup, hlookup_ge, vlookup, get

Kullanıcı profilleri

Yapı mühendisleri

Kirişler, kolonlar, temeller için el hesaplamaları — okunabilir bir belgede doğrudan. Mevcut CalcPAD dosyalarınızı taşıma olmadan açın.

BIM modelleyicileri

Hesaplamaları doğrudan IFC elemanlarına bağlayın. Değerlerin elle aktarımı yok — kontrol modelde yaşar.

Eğitim

Yapı mühendisliği öğrencileri uygulamada karşılaşacakları gerçek sözdizimi ile hesaplamayı öğrenir. Açık kaynak — lisans maliyeti yok.

FEM geliştiricileri

Kendi FEM uygulamanızda pre/post-processing veya code-checking için @ifc-calc/core'u gömün. TypeScript kütüphanesi, npm-installable.
