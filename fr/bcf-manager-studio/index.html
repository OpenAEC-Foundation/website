BCF Manager Studio

Plateforme open source de gestion d'incidents BCF 2.1 pour projets BIM. Gérez les tickets, communiquez avec les équipes et liez aux modèles IFC.

GitHub
En développement BCF 2.1 · REST API Self-hosted · Docker € 0

Pourquoi BCF Manager Studio ?

Les outils BCF existants font souvent partie de plateformes BIM propriétaires et coûteuses. BCF Manager Studio offre une alternative autonome et open source que chacun peut utiliser — gratuit, sans frais de licence, sans verrouillage propriétaire.

La plateforme fonctionne localement ou sur votre propre serveur. Vos données restent les vôtres. Connectez-la à votre propre visualiseur IFC, partagez des tickets avec votre équipe et exportez vers tout logiciel compatible BCF.

buildingSMART

Qu'est-ce que BCF ?

BIM Collaboration Format (BCF) est un standard ouvert (buildingSMART) pour échanger tickets et commentaires entre logiciels BIM. Il permet de signaler, discuter et résoudre des problèmes dans un modèle de bâtiment — quel que soit le logiciel utilisé par les parties prenantes.

  • Standard ouvert BCF 2.1 en fichier (XML) et en API REST

  • Indépendant du logiciel Fonctionne avec tout outil BIM compatible BCF

  • Points de vue Captures visuelles du modèle 3D pour chaque ticket

  • Métadonnées Priorité, statut, attribution, échéances, étiquettes

Fonctionnalités

Gestion d'incidents BCF 2.1

Créez, modifiez et gérez des tickets conformes au standard BCF 2.1. Support complet pour sujets, commentaires, points de vue et captures d'écran.

Points de vue avec captures 3D

Liez des points de vue visuels aux tickets avec position de caméra, sélection et visibilité. Directement visibles dans votre visualiseur IFC.

Collaboration d'équipe

Attribuez des tickets aux membres de l’équipe, fixez des échéances, ajoutez des commentaires et suivez le statut. Membres par projet, connexion par authentification unique (OIDC).

Import/export BCF XML

Importez et exportez des fichiers BCF (format XML) pour l'échange avec Solibri, Navisworks, BIMcollab et autres logiciels compatibles BCF.

API REST (BCF API 2.1)

Les 29 endpoints de la BCF API 2.1, plus des clés API par projet pour relier d’autres outils, comme le BIM Validator.

Gestion de projets

Organisez les tickets par projet avec étiquettes, priorités, phases et filtres. Tableau de bord clair avec statistiques.

Intégration IFC

Reliez les tickets aux éléments IFC par leur GlobalId, pour qu’un visualiseur BCF aille directement au bon élément du modèle.

Auto-hébergé

Exécutez la plateforme sur votre propre serveur ou localement. Contrôle total de vos données, sans dépendance cloud.

Stockage cloud

Conservez les tickets par projet dans votre propre Nextcloud, à côté des modèles IFC. Plusieurs organisations sur une seule installation.

Technologie

Rust · Axum PostgreSQL React TypeScript BCF 2.1 BCF API 2.1 OIDC Docker

Un backend Rust (Axum) avec PostgreSQL pour la vitesse et la fiabilité, un frontend React et TypeScript dans le style OpenAEC, et Docker Compose pour tout démarrer sur votre propre serveur en une commande.
