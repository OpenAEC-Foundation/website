Hommage aux pionniers de l'open source. Avant que ce soit à la mode. Avant l'IA. Quand Microsoft qualifiait encore Linux de cancer. Ils ont bâti les fondations sur lesquelles nous continuons à construire.

L'open source gagne

Les chiffres ne mentent pas. L'open source n'est plus une alternative — c'est la norme.

Linux

Pionniers — les personnes

Les personnes qui ont eu le courage de penser différemment. Qui ont offert leur travail au monde pour qu'il devienne meilleur.

Linus Torvalds 🇫🇮

Créateur du noyau Linux et de Git
"Talk is cheap. Show me the code."

L'homme qui a construit le système d'exploitation du monde entier comme projet personnel, et qui a ensuite créé Git pour permettre la collaboration de milliers de développeurs.

Guido van Rossum 🇳🇱

Créateur de Python
"Beautiful is better than ugly. Simple is better than complex."

Le Néerlandais qui a créé le langage de programmation le plus populaire au monde. Python est le langage de l'IA, de la science et du web.

LinkedIn

Ton Roosendaal 🇳🇱

Créateur de Blender, Blender Foundation

En 2002, a réuni 100 000 € en financement participatif en 7 semaines pour racheter Blender à NaN Technologies en faillite. Aujourd'hui, Blender est le standard de l'industrie pour la création 3D.

LinkedIn

Thomas Krijnen 🇳🇱

Créateur d'IfcOpenShell, AECgeeks

L'homme derrière la révolution du BIM ouvert. IfcOpenShell est l'épine dorsale des outils BIM open source et permet de lire, écrire et manipuler des fichiers IFC.

LinkedIn

Dion Moult 🇦🇺

Développeur principal de Bonsai (BlenderBIM), contributeur IfcOpenShell

Pionnier des outils BIM open source. Bonsai permet de créer des modèles BIM complets dans Blender, entièrement en open source.

LinkedIn

Mark Shuttleworth 🇿🇦

Fondateur d'Ubuntu/Canonical
"Computer is not a device anymore. It is an extension of your mind."

Premier Africain dans l'espace. A fondé Canonical et rendu Linux accessible à tous avec Ubuntu.

LinkedIn

Rushabh Mehta 🇮🇳

Fondateur d'ERPNext/Frappe

ERP open source qui défie SAP. Frappe Framework et ERPNext prouvent que les logiciels d'entreprise n'ont pas besoin d'être chers et fermés.

LinkedIn

Antonio González Viegas 🇪🇸

Fondateur de That Open Company (IFC.js)

« Un architecte qui s'est mis à coder » — a apporté le BIM ouvert sur le web. That Open Company permet de visualiser et de modifier des modèles IFC directement dans le navigateur.

LinkedIn

Richard Stallman 🇺🇸

Fondateur du projet GNU et de la Free Software Foundation (1983)
"Free software is a matter of liberty, not price."

Le parrain du logiciel libre. Sans GNU et la GPL, il n'y aurait pas de mouvement open source tel que nous le connaissons.

Dennis Ritchie 🇺🇸 †2011

Créateur du C et co-créateur d'UNIX

Sans le C et UNIX, il n'y aurait ni Linux, ni Python, ni internet tel que nous le connaissons. Le héros discret dont le travail a rendu littéralement tout possible.

Graydon Hoare 🇨🇦

Créateur du langage de programmation Rust (chez Mozilla)

Rust : le langage sur lequel OpenAEC est construit. Sécurité, rapidité et fiabilité sans compromis.

Solomon Hykes 🇫🇷

Créateur de Docker

A révolutionné le déploiement logiciel avec les conteneurs. Docker a permis d'exécuter des logiciels de manière identique partout.

Frank Karlitschek 🇩🇪

Fondateur de Nextcloud

Alternative open source au stockage cloud. Nextcloud redonne aux utilisateurs le contrôle de leurs propres données.

Projets open source

Les outils et frameworks sur lesquels OpenAEC est construit. Chaque projet représente des années de travail non rémunéré par des développeurs passionnés.

Linux

Le système d'exploitation qui fait tourner le monde. Des serveurs aux smartphones.

Python

Le langage que tout le monde peut apprendre. Du scripting au machine learning.

Blender

La création 3D pour tous. Modélisation, animation, rendu et bien plus.

IfcOpenShell

L'épine dorsale du BIM ouvert. Lecture, écriture et manipulation de fichiers IFC.

Bonsai (BlenderBIM)

Modélisation BIM dans Blender. Création BIM complète, entièrement en open source.

That Open Company

Le BIM ouvert sur le web. Visualisation et modification de modèles IFC dans le navigateur.

ERPNext / Frappe

ERP open source. Comptabilité, gestion de projet, CRM et bien plus.

Nextcloud

Gestion de fichiers et collaboration. Vos données, votre serveur, vos règles.

Docker

Des conteneurs pour le déploiement. Exécuter des logiciels de manière identique partout.

Rust

Langage de programmation système sûr. La rapidité sans compromis sur la sécurité.

LibreOffice

Bureautique libre. Documents, tableurs et présentations pour tous.

Ubuntu

Linux pour tous. Le système d'exploitation qui a amené Linux sur le bureau.

Git

Le contrôle de version pour le monde entier. Collaborer sur du code à l'échelle mondiale.

Three.js

Graphismes 3D sur le web. La base des expériences 3D interactives dans le navigateur.

PDF.js

Rendu PDF dans le navigateur. Alternative open source aux visualiseurs PDF propriétaires.

Tauri

Applications de bureau légères. Technologies web avec performance native et petits bundles.

Nous nous tenons sur les épaules de géants. Chaque ligne de code que nous écrivons a été rendue possible par le courage de ces pionniers. L'open source n'est pas une mode — c'est l'avenir.
