OpenAEC Docs

Les documents des projets BIM en un seul endroit

Un prototype de système de gestion documentaire pour projets BIM : un serveur en Rust et une interface web en React, au-dessus de Nextcloud. Des dossiers fixes par projet, un manifeste des modèles et des lots d'issues associés, et une connexion via OIDC. Le développement est à l'arrêt depuis avril 2026.

Ce que fait le prototype

Commencez par les points forts ou choisissez un thème.

01 Fichiers

Les fichiers de projet directement dans Nextcloud

Envoyez, ouvrez et supprimez des fichiers et créez des dossiers, par projet. Les fichiers se trouvent dans un dossier de projet sur Nextcloud ; le serveur y accède via WebDAV et conserve les métadonnées dans PostgreSQL.

02 Projets

Dossiers de projet fixes

Une structure fixe par projet, comme modèles, plans, calculs et rapports, avec les types de fichiers autorisés par dossier. Vous pouvez lier un dossier de projet Nextcloud existant au lieu d'en créer un nouveau.

03 Manifeste

Ce qui appartient à un projet

Un projet peut avoir plusieurs manifestes qui indiquent quels modèles IFC, lots d'issues et rapports lui appartiennent, pour que les autres outils OpenAEC les trouvent. La vue du projet les affiche dans un panneau latéral.

04 Intégrations

Connexion, organisations et intégrations

Connexion par authentification unique (OIDC), avec plusieurs organisations sur une même installation, chacune avec son propre Nextcloud. Intégrations avec le BIM Validator et la plateforme BCF d'OpenAEC, et tout via une API REST.

    Envoyer, ouvrir, supprimer et créer des dossiers, par projet.

  • Nextcloud via WebDAV

    Les fichiers restent dans Nextcloud ; le serveur les lit et les écrit via WebDAV.

  • Ruban

    Un ruban avec Fichier, Accueil, Documents et Affichage, comme dans les autres applications OpenAEC.

Questions fréquentes

OpenAEC Docs est-il encore développé ?

Non, pas pour l'instant. La dernière modification date d'avril 2026 et l'application ne figure plus sur la page d'accueil. Pour les fichiers de projet dans le cloud, OpenAEC travaille désormais au SuperCloud.

Puis-je l'essayer ?

Il n'existe ni version hébergée ni version publiée. Pour l'essayer, vous pouvez compiler vous-même le code source depuis GitHub et le lancer avec Docker Compose ; il vous faut alors aussi un Nextcloud, une base PostgreSQL et un fournisseur OIDC.

Qu'est-ce qu'un système de gestion documentaire pour projets BIM ?

Un lieu unique qui rassemble tous les documents d'un projet, des modèles et plans aux calculs et rapports, avec une structure de dossiers fixe et des règles sur ce qui va où. OpenAEC Docs y ajoute un manifeste, pour que d'autres outils sachent aussi quels modèles et lots d'issues appartiennent à un projet.

Pourquoi Nextcloud ?

Nextcloud est open source et auto-hébergeable : les fichiers restent sur un serveur que vous choisissez. OpenAEC Docs conserve les fichiers eux-mêmes dans Nextcloud et seulement l'administration dans sa propre base de données.

Quel est le lien avec le SuperCloud ?

Ce sont des projets distincts. OpenAEC Docs s'appuyait sur Nextcloud et la bibliothèque openaec-cloud ; le SuperCloud a son propre serveur de stockage avec espaces, versions et une application de bureau pour synchroniser.

Sous quelle licence est le code ?

Le code source est public sur GitHub, mais il n'a pas encore de licence. Si vous souhaitez l'utiliser, écrivez à info@open-aec.com.
