Extension pour Open 2D Studio

Drawing Statistics

Extension qui affiche le nombre de formes et des statistiques de dessin. Ajoute un onglet ruban Add-Ins avec un bouton Shape Count et une commande terminal.

Télécharger v1.0.1 (1,4 Ko) Voir le code source

Fonctionnalités

Onglet ruban Add-Ins

Ajoute un bouton Shape Count à l'onglet ruban Add-Ins dans Open 2D Studio.

Commande terminal

Enregistre une commande terminal stats show pour afficher les statistiques depuis la ligne de commande.

Comptage d'entités

Compte toutes les entités par type dans le dessin actuel.

Nécessite Open 2D Studio v0.15.0 ou ultérieur.
