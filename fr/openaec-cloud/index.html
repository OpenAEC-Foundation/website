OpenAEC SuperCloud

La plateforme cloud, comptes et SSO d’OpenAEC. Une seule connexion pour tout l’écosystème, avec stockage, partage et synchronisation sur votre propre serveur Nextcloud.

Pourquoi OpenAEC SuperCloud ?

Les fichiers des projets de construction sont souvent dispersés entre Dropbox, OneDrive et les serveurs des éditeurs de logiciels. C’est alors un autre qui décide où se trouvent vos données et ce qu’elles coûtent.

SuperCloud fonctionne sur votre propre Nextcloud. Fichiers, comptes et tickets restent sur votre serveur, et les outils OpenAEC y lisent et écrivent directement.

Nextcloud

Trois composants

SuperCloud n’est pas une application isolée, mais la couche sous l’écosystème. Ces composants sont en cours de développement.

  • OpenAEC Cloud pour le bureau Un client de synchronisation comme Dropbox : reliez un dossier local à votre Nextcloud, synchronisez dans les deux sens et créez des liens de partage.

  • Stockage cloud pour les outils Une bibliothèque partagée qui permet à des outils comme BCF Manager Studio de conserver leurs données de projet dans Nextcloud, avec plusieurs organisations sur un seul serveur.

  • Un seul compte OpenAEC Une seule connexion pour toutes les applications. Les jetons d’accès sont vérifiés de façon centrale, y compris pour les services d’IA qui fonctionnent avec des crédits.

Fonctionnalités

Synchronisation bidirectionnelle

Votre dossier local et votre dossier Nextcloud restent identiques : les fichiers nouveaux et modifiés circulent dans les deux sens, les autres sont ignorés.

Partager par lien

Créez en un clic un lien de partage pour un dossier ou un fichier, via votre propre serveur plutôt qu’un service externe.

Coches dans l’Explorateur

Sous Windows, un dossier devient un dossier cloud comme avec OneDrive : les fichiers sont présents en espace réservé et ne se téléchargent qu’à l’ouverture.

Plusieurs organisations

Une installation sert plusieurs organisations, chacune avec ses propres projets et son stockage.

Manifeste de projet

Pour chaque projet, un manifeste indique quels modèles IFC et ensembles de tickets en font partie, pour que les outils trouvent les données des autres.

Une seule connexion

Un compte pour toutes les applications OpenAEC. Le client de bureau utilise pour l’instant un mot de passe d’application Nextcloud ; l’authentification unique suivra.

Technologie

Nextcloud WebDAV Rust Tauri 2 SolidJS Python · FastAPI JWKS

Le client de bureau est construit avec Tauri 2, Rust et SolidJS et communique avec votre serveur via WebDAV et l’API de partage de Nextcloud. La bibliothèque de stockage est écrite en Rust, la vérification des comptes pour les services en Python.
