OpenAEC Foundation

Pour démarrer

Commencez avec l'écosystème OpenAEC en 5 étapes. Sans inscription, sans carte bancaire, sans verrouillage propriétaire — téléchargez et lancez-vous.

1

Choisissez l'outil adapté à votre travail

Explorez l'écosystème complet et choisissez l'outil pour votre tâche. Pour l'annotation PDF et le balisage de plans : Open PDF Studio. Pour le dessin 2D CAO : Open 2D Studio. Pour les calculs de déperditions selon NEN 12831 et ISSO 51:2023 : Open Heatloss Studio. Pour la validation de modèles IFC : BIM Validator. Pour la gestion d'incidents BCF : BCF Manager Studio. Pour l'estimation de coûts : Open Calc Studio.

Voir les 18+ outils →
2

Téléchargez l'installateur ou essayez la démo en ligne

Chaque page produit propose des téléchargements pour Windows (.exe ou MSI), macOS (.dmg), Linux (.deb, .AppImage, .snap, .rpm) et Android (.apk). Ou cliquez sur « Démo en ligne » pour démarrer directement dans votre navigateur — sans installation.

Exemple : téléchargements Open PDF Studio →
3

Installez et lancez l'outil

Les outils OpenAEC sont légers (8–20 Mo) grâce à Tauri 2 + Rust — bien plus petits que les applications Electron. Sur Windows, choisissez entre installation système (tous utilisateurs, admin requis) ou installation utilisateur (sans admin). Sur macOS, glissez l'application dans Applications. Sur Linux, double-cliquez sur le .deb ou .AppImage. Aucun compte requis pour démarrer.

En savoir plus sur l'architecture technique →
4

Travaillez avec IFC ou importez vos données existantes

Tous les outils OpenAEC communiquent via IFCX, une extension ouverte d'IFC qui prend en charge les espaces de noms pour calculs, rapports et métadonnées. Importez des modèles IFC 2x3, IFC 4 et IFC 4.3 — y compris les schémas civils comme IfcRoad, IfcRail, IfcBridge, IfcTunnel et IfcMarineFacility. Les données circulent sans accroc entre tous les outils.

Plus sur IFCX et les schémas civils →
5

Envoyez vos retours ou contribuez

Signalez bugs et demandes via GitHub (github.com/OpenAEC-Foundation). Rejoignez la communauté WhatsApp ou écrivez à info@open-aec.com. Pour les entreprises : demandez un devis pour conseil, hébergement managé ou extensions sur mesure. Tous les outils sont sous LGPL-3.0 — forkez, modifiez, contribuez.
