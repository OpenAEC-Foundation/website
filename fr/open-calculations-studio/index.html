Open Calculations Studio

Application de bureau open source pour les calculs structuraux — inspirée de CalcPAD, avec export direct vers IFC4x3 STEP et IFCX JSON-LD. Anciennement Ifc-Calc, reconstruite sous l'égide de l'OpenAEC Foundation.

Qu'est-ce qu'Open Calculations Studio ?

Open Calculations Studio est un outil moderne et open source pour les calculs structuraux — inspiré de CalcPAD, l'outil largement utilisé par les ingénieurs structure néerlandais et européens. Nous avons reconstruit tout le moteur de calcul en TypeScript avec prise en charge de la syntaxe CalcPAD, et ajouté l'export IFC et IFCX en direct pour que les calculs s'intègrent directement avec les modèles BIM.

  • Compatible CalcPAD — les fichiers .cpd existants fonctionnent sans modification
  • Gestion des unités — mm, kN, N/mm², mm⁴ via mathjs
  • Export IFCX + IFC4x3 STEP en direct — le calcul devient immédiatement un élément BIM
  • Rendu KaTeX — formules mathématiques avec vraies fractions, indices/exposants et lettres grecques
  • Dessins SVG — schémas paramétriques directement dans le calcul
  • Cas de charge — ELS / ELU / sismique dans des onglets distincts
  • Utilisable comme bibliothèque — à intégrer dans des applications EF ou des vérifications normatives

Pourquoi Open Calculations Studio ?

CalcPAD est utilisé depuis des années par les ingénieurs structure néerlandais pour les calculs manuels. Mais il est closed-source, ne fonctionne que sur Windows et n'a pas d'intégration BIM native. Open Calculations Studio apporte la fonctionnalité CalcPAD aux technologies web modernes : multiplateforme, open source, avec export IFC direct.

Le fichier de régression 2259-Intertek-units.cpd de 1094 lignes s'évalue avec 0 erreur et produit 6 dessins SVG. Suffisant pour de vrais calculs de projet.

Fonctionnalités

Formules avec unités

Travaillez avec mm, kN, N/mm², mm⁴ et toutes les unités SI. Mathjs gère l'arithmétique sensible aux unités et la simplification automatique (b*h → mm²).

Mise en forme mathématique

Rendu KaTeX avec vraies fractions, exposants, indices et lettres grecques (σ, ε, ρ, Φ, ψ). Les formules affichent nom = formule = valeurs remplies = résultat sur une ligne.

Aperçu en direct

Éditeur en split-pane (CodeMirror 6) avec coloration syntaxique pour .cpd. L'aperçu se met à jour pendant que vous tapez.

Cas de charge

Onglets pour ELS / ELU / sismique, etc., chacun avec ses propres valeurs pour les variables d'entrée. Un document, plusieurs scénarios.

Compatible CalcPAD

Entièrement compatible avec les fichiers .cpd existants : #if/#else if/#end if, #repeat, #for, macros #def, #include, $Plot, matrices, lookups.

Export IFC4x3 STEP

Détecte les éléments structuraux via des noms de variables conventionnels (b_fdn, l_fdn, D_paal, M_Ed, R_c_d). Génère un squelette valide Project → Site → Building → Storey.

IFCX JSON-LD

Export IFCX en direct (draft) — la nouvelle génération d'IFC avec espaces de noms pour calculs, normes et métadonnées. Calcul et modèle BIM dans un seul format.

Dessins SVG

Macros SVG paramétriques avec interpolation de valeurs. @img(file.svg) intègre des dessins externes en ligne. @svg ... @end pour du SVG manuscrit.

Onglet IFC

Visualiseur STEP et visualiseur IFCX JSON intégrés avec coloration syntaxique. Les types d'entités sont cliquables et renvoient à la documentation buildingSMART.

Import GEF

@gef name — utilisez les données de sondage directement dans les calculs de fondation. S'intègre avec Open Geotechniek Studio.

5 thèmes

Light, Forge, OpenAEC, Blueprint et Contrast — tous basés sur les design tokens OpenAEC. Choisissez ce qui fonctionne le mieux pour vous.

Export PDF

Export PDF prêt à imprimer via shell Tauri avec aperçu headless. Prêt pour le dossier projet ou une revue tierce.

Mode bibliothèque

Utilisez @ifc-calc/core en tant que bibliothèque TypeScript : parser, évaluer, rendre, générer IFC/IFCX depuis vos applications FEM ou contrôles normatifs.

Compatibilité CalcPAD

Entièrement compatible sous-ensemble avec les fichiers CalcPAD du monde réel. Fonctionne directement sur vos documents .cpd existants :

  • "Title, 'prose, // comment
  • #if … #else if … #else … #end if, #hide / #show / #pre / #post
  • #repeat n … #end repeat en #for var = lo : hi … #loop (incl. nested)
  • #def name(p1; p2; …) … #end def macros, #def Name$ = literal constants
  • #include filename.cpd — externe macro-libraries en SVG drawings
  • $Plot{ … @ x = lo : hi } — inline parametrische plots
  • Subscript-comma's (V_b,0), $-getypeerde refs, matrix [a;b|c;d]
  • Format-specs (:F2), dotted/percent identifiers
  • mathjs Matrix-aware take, hlookup, hlookup_ge, vlookup, get

Profils d'utilisateurs

Ingénieurs structure

Calculs manuels pour poutres, poteaux, fondations — directement dans un document lisible. Ouvrez vos fichiers CalcPAD existants sans migration.

Modeleurs BIM

Liez les calculs directement aux éléments IFC. Pas de transfert manuel de valeurs — la vérification vit dans le modèle.

Enseignement & formation

Les étudiants en génie civil apprennent à calculer avec la vraie syntaxe qu'ils rencontreront en pratique. Open source — pas de frais de licence.

Développeurs FEM

Intégrez @ifc-calc/core dans votre propre application FEM pour pré/post-traitement ou contrôle normatif. Bibliothèque TypeScript, installable via npm.

Technologie

TypeScript React 19 Rust Tauri 2 mathjs KaTeX CodeMirror 6 Vite npm workspaces

Monorepo avec trois packages : @ifc-calc/core (parser + évaluateur + générateur IFC en bibliothèque TypeScript), @openaec/calculations-studio (application de bureau Tauri 2 avec interface React 19), et @ifc-calc/web (build navigateur uniquement). Multiplateforme : Windows, macOS, Linux.
