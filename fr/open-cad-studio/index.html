Qu'est-ce qu'Open CAD Studio ?

Open CAD Studio est un projet CAO open source indépendant qui comble une lacune majeure de l'outillage AEC : une application CAO moderne, performante, nativement compatible DWG/DXF qui ne dépend pas d'Autodesk, de Bricsys ou d'autres éditeurs commerciaux. Entièrement écrite en Rust, avec rendu accéléré par GPU via wgpu et une interface interactive en iced.

  • La fondation OpenAEC considère Open CAD Studio comme une extension naturelle de l'écosystème. Le projet n'est pas développé par nous, mais s'inscrit dans notre mission : promouvoir les logiciels open source pour toute la chaîne AEC. Nous y faisons activement référence et encourageons la collaboration.

  • Licence GPL-3.0 (à noter : différente de nos propres outils LGPL-3.0, qui est plus permissive pour l'usage en bibliothèque).

Formats de fichiers — DWG & DXF natifs

Peut-être la fonctionnalité la plus importante : Open CAD Studio lit et écrit DWG et DXF nativement, dans toutes les versions de R13 à R2018. Pas de convertisseurs, pas de contournements, pas de bibliothèques Autodesk.

DWG (R13–R2018)

Lecture et écriture natives de fichiers DWG — le format de facto standard de l'industrie. Sans licences de bibliothèques tierces.

DXF (R13–R2018)

Lecture/écriture DXF complète, versions modernes incluses. Compatible avec AutoCAD, BricsCAD, LibreCAD et toute application CAO supportant DXF.

STL / STEP / OBJ

Export vers STL et STEP AP203 pour impression 3D et FAO. Import OBJ pour modèles 3D depuis d'autres sources.

Plot PDF

Plottez les layouts directement en PDF — avec les bons formats de papier lus depuis les PlotSettings embarqués.

WBLOCK

Écrivez des entités sélectionnées ou un bloc vers un fichier externe pour réutilisation.

XREF

Références externes (xrefs) — attacher, recharger et résoudre automatiquement, comme dans AutoCAD.

Dessin 2D

Suite complète de dessin 2D avec toutes les commandes attendues d'une application CAO professionnelle :

Géométrie de base

LINE, PLINE, RECTANG, POLYGON, CIRCLE, ARC, ELLIPSE, SPLINE

Modification

OFFSET, TRIM, EXTEND, FILLET, BREAK, STRETCH, LENGTHEN — fonctionne sur lignes, arcs, ellipses, polylignes et splines

Transformations

ARRAY, MIRROR, MOVE, COPY, ROTATE, SCALE, EXPLODE

Hachures

HATCH et HATCHEDIT avec édition de motif, d'échelle et d'angle.

Propriétés

MASSPROP — surface, périmètre et centre de gravité des entités sélectionnées.

Édition de texte

DDEDIT — double-cliquez pour éditer le texte. MTEXT, TEXT, DTEXT avec navigateur de polices.

Modélisation 3D

Capacités complètes de modélisation 3D avec tessellation des solides ACIS :

Primitives

BOX, SPHERE, CYLINDER — solides de base pour la modélisation paramétrique.

Extrusion & révolution

Solides à partir de profils : EXTRUDE pour l'extrusion linéaire et REVOLVE pour la rotation autour d'un axe.

Loft & sweep

LOFT entre plusieurs profils, SWEEP le long d'un chemin quelconque.

Array 3D

ARRAY3D — réseaux rectangulaires ou polaires en 3D.

Tessellation ACIS

Affiche les entités 3DSOLID, REGION et BODY — les solides issus de DWG/DXF s'affichent correctement.

Accéléré par GPU

Rendu basé sur wgpu. Interaction fluide avec de grands modèles, même avec de nombreux solides à la fois.

Annotations & cotations

Cotation complète, GD&T, leaders, tableaux et mlines — tout avec des gestionnaires de styles et un comportement DIMSTYLE correct (DIMASZ, DIMSCALE, DIMEXO, DIMEXE, …).

Dimensies

linear, aligned, angular, radial, diameter, ordinate

Tekst

MTEXT, TEXT, DTEXT met font browser (STYLE DIALOG)

Leaders

MLEADER met straight en spline paths · MLEADERSTYLE manager

GD&T tolerances

feature control frames

Tables

TABLE entities · TABLESTYLE manager

MLines

MLINE met MLSTYLE manager en EXPLODE-ondersteuning

Paper space & mises en page

Multi-onglets

Model space + nombre illimité d'onglets paper space. Position de la caméra et zoom enregistrés par layout.

Projection viewport

Le contenu du modèle est correctement projeté dans les rectangles viewport de paper space. Double-clic pour superposition MSPACE inline.

Préréglages viewport

VPORTS — configurations single, 2H, 2V, 4-way.

Styles de tracé

PLOTSTYLEPANEL et STYLESMANAGER — éditeur de tables de style de tracé CTB/STB.

PRINT

Envoyez directement les layouts vers l'imprimante système avec les bons formats de papier issus des PlotSettings embarqués.

Gestionnaire de layouts

LAYOUTMANAGER / LAYOUTPANEL — interface graphique pour la gestion des layouts.

Technologie

Rust iced (UI) wgpu (GPU) DWG R13–R2018 DXF R13–R2018 ACIS tessellation GPL-3.0

Entièrement écrit en Rust — sûreté mémoire, performances rapides, compile pour Windows, macOS et Linux. Interface via iced, rendu GPU via wgpu. DWG/DXF natifs sans verrouillage propriétaire.
